## 1. ImplementManager — 能力注入总线

命名空间 `Interface.ImplementManager`

```csharp
public interface IImplementManager
{
    T Get<T>() where T : class;                                   // 取默认实现；未注册返回 null，不抛异常
    bool TryGet<T>(out T implementation, string name = "") where T : class;  // 查询（默认或命名）；未找到返回 false
    bool IsRegistered<T>() where T : class;                       // 是否存在任意默认或命名实现
    void Register<TInterface>(TInterface instance, string name = "") where TInterface : class;  // 注册（默认或命名）
    void UnRegister<T>(T instance) where T : class;               // 注销；重复/未注册抛 InvalidOperationException
}
```

> 实现侧语义（用于复刻，非接口定义）：按 `Type → Bucket` 存实现，每个 bucket 分 `DefaultImplementation`（单槽）与 `NamedImplementations`（字典）两条通道；`name` 为空走默认槽，非空走命名槽。

## 2. Application — 应用与模块生命周期

命名空间 `Interface.Application`

```csharp
public interface IApplicationInfo
{
    string VersionInfo();      // 版本信息
    string BuildInfo();        // 构建信息
    int HotUpdateInfo();       // 热更版本号
}

public interface IApplication : IUpdatable
{
    void Init();
    void Release();
    void InitModule(IApplicationModule module);
    void ReleaseModule(IApplicationModule module);
}

public interface IApplicationModule : ICustomField, IUpdatable
{
    string ModuleName { get; }
    void Init(IImplementManager implementManager);
    void Release();
    void RegisterImplement(IImplementManager implementManager);
    void UnRegisterImplement(IImplementManager implementManager);
}

public interface IUpdatable
{
    // 由 GameMain 统一驱动帧更新：deltaTime = 帧间隔，elapsedTime = 自应用启动累计时间
    void OnUpdate(float deltaTime, float elapsedTime);
}
```

> `IApplicationModule` 是**业务模块统一入口**：`Init` 注入 `IImplementManager` → `RegisterImplement` 注册自身实现 → 结束时 `UnRegisterImplement` → `Release`。`ICustomField` 见下篇 Logger 域。

### 3.6 IScreenAdaptable（屏幕适配）

```csharp
public enum ScreenRotation { Rotation0 = 0, Rotation90 = 1, Rotation180 = 2, Rotation270 = 3 }

public readonly struct NativeWindowMetrics   // 原生窗口度量，构造时校验所有值域
{
    int WindowWidthPx { get; }
    int WindowHeightPx { get; }
    ScreenRotation DisplayRotation { get; }
    int DensityDpi { get; }
    int InsetTopPx { get; }
    int InsetBottomPx { get; }
    int InsetLeftPx { get; }
    int InsetRightPx { get; }
    float PhysicalXDpi { get; }
    float PhysicalYDpi { get; }
    int ContentWidthPx => WindowWidthPx - InsetLeftPx - InsetRightPx;
    int ContentHeightPx => WindowHeightPx - InsetTopPx - InsetBottomPx;
    float AspectRatio => ContentWidthPx / (float)ContentHeightPx;
    // 构造器校验：宽高/density > 0；inset ≥ 0 且不能吞掉整个内容区；dpi 非负非 NaN/Inf；rotation 必须已定义
}

public enum ScreenChangeType { Rotation, SizeChanged }
public enum ScreenChangeApplyResult { Succeeded, Failed }

public readonly struct ScreenChangeInfo   // 屏幕变化事件；changeSetId/sequenceId 必须 > 0
{
    long ChangeSetId { get; }
    long SequenceId { get; }
    ScreenChangeType Type { get; }
    NativeWindowMetrics Previous { get; }
    NativeWindowMetrics Current { get; }
}

public interface IScreenAdaptable
{
    void ApplyCurrentScreen(NativeWindowMetrics current);   // 应用当前屏幕
    void ApplyScreenChange(ScreenChangeInfo change);        // 应用一次屏幕变化
}
```
