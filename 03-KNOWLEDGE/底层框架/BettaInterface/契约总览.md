# BettaInterface 契约总览

> BettaInterface 是**纯契约层，零实现、零依赖**。本目录把它整理到「照文档即可重建」的粒度。
> 完整签名见 [[03-KNOWLEDGE/底层框架/BettaInterface/契约清单-上|契约清单·上（基础能力）]] 与 [[03-KNOWLEDGE/底层框架/BettaInterface/契约清单-下|契约清单·下（业务能力）]]。

---

## 一、复刻须知（全局约定）

| 项 | 约定 |
|---|---|
| 定位 | 只定义接口 / 枚举 / 数据结构，**不含实现、不含平台 SDK 配置、不含 Unity 类型依赖之外的强绑定** |
| asmdef | `Betta.Interface.asmdef`：`references: []`（零依赖），`autoReferenced: true` |
| package.json | 包名 `com.betta.unity.interface`，依赖仅 `com.unity.ugui` |
| 命名空间 | `Interface.<域>`；**唯一特例**：`Audio` 目录的命名空间是 `Interface.Sound` |
| 依赖 Unity | 部分接口引用 `UnityEngine`（Transform / RectTransform / Camera / Sprite / GameObject / Vector2 / Vector3）与 `UnityEngine.EventSystems.PointerEventData` |

### 完整目录清单（25 个命名空间，26 个目录）

```
ActionFeedback  Activity  Ad  Application  Audio(=Sound)  Cameras  Flow  Game
GM  Haptic  ImplementManager  Input  Item  ItemGraphic  Logger  Notification
PlayerInfo  Purchase  RedDot  Resource  Tutorial  UI  UIEntry  UIPanelBanner  UserLayer
```

> 目录 `Audio` 的命名空间为 `Interface.Sound`（唯一不一致项，复刻时注意）。

## 二、使用范式（三条铁律）

### 2.1 接口优先

```csharp
// 消费侧：面向接口，绝不 new 具体类
var ui = implementManager.Get<IUIManager>();
var res = implementManager.Get<IResourceSystem>();
```

### 2.2 实现只在实现层注册

- `BettaFramework` 注册 UI 相关（`IUIManager` / `IUIWindow` / `ILogger`…）
- `BettaSDK` 注册资源 / 登录 / 支付 / 广告 / 音频（`IResourceSystem` / `IAdSystem` / `IAudioSystem`…）

### 2.3 生命周期一致性

| 接口 | 用途 |
|---|---|
| `IApplicationModule` | 业务模块入口：`Init(implementManager)` → `RegisterImplement` → … → `UnRegisterImplement` → `Release` |
| `IUpdatable` | 需逐帧更新的系统：`OnUpdate(deltaTime, elapsedTime)` 由上层统一驱动 |
| `IApplication` | 应用根：`Init` / `Release` + 模块的 `InitModule` / `ReleaseModule` |
