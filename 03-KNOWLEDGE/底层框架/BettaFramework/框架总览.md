# BettaFramework 框架总览

> BettaFramework 是**运行时基础设施层**：UI 窗口管理、消息总线、状态机、本地化、屏幕适配、表达式引擎、配置工具。
> 它是 `BettaSDK` 的下游、玩法层的上游。本目录按「照文档即可重建」粒度整理，核心机制分册深挖，工具/控件索引级。

- [[03-KNOWLEDGE/底层框架/BettaFramework/MessageDispatch-消息总线|MessageDispatch-消息总线]]
- [[03-KNOWLEDGE/底层框架/BettaFramework/Locale-本地化|Locale-本地化]]
- [[03-KNOWLEDGE/底层框架/BettaFramework/StateMachine-状态机|StateMachine-状态机]]

## 一、定位与边界

| 项 | 值 |
|---|---|
| package 名 | `com.betta.unity.framework`（version 0.0.1） |
| asmdef | `Scripts/Runtime/BettaFramework.asmdef`，`autoReferenced: true` |
| 根命名空间 | `Betta.Framework` |
| 引擎要求 | Unity 2022.3（`package.json` 声明） |
| 定位 | 通用运行时基建，**不绑定具体玩法**；玩法层通过 `IUIManager` 等接口获取 |

`package.json` 依赖：`com.unity.ugui 2.0.0`、`com.betta.unity.sdk 0.0.1`。

> [!warning] 修正旧结论
> 早前记录「Framework → SDK 仅 `package.json` 声明、asmdef 层看不到这条边」是**误判**。实测 asmdef 层确实引用了 `BettaSDK`（GUID `f6687d67...`）。依赖图以本表为准。

- 第三方：`Newtonsoft.Json`（LocaleAsset）、`ProtoBuf`（LocaleAsset / LocaleStringRow / Expression）

## 二、目录结构（Runtime）

```
Scripts/Runtime/
├── BettaFrameworkAssemblyInfo.cs    # InternalsVisibleTo 测试程序集
├── BettaFrameworkRoot.cs           # 启动常驻入口（MonoBehaviour）
├── Core/BettaFrameworkConfig.cs    # 框架级 ScriptableObject 配置
├── UIManager/                      # ★ 窗口系统（8 文件 / 3239 行）
├── UI/                             # UI 控件 + FontArt 字体美术（17 文件 / 3096 行）
├── Expression/                     # 表达式引擎（4 文件 / 1200 行）
├── Locale/                         # ★ 本地化（4 文件 / 651 行）
├── Message/                        # ★ 消息总线（2 文件 / 480 行）
├── SceneState/                     # ★ 状态机（2 文件 / 169 行）
├── Utils/                          # 工具类（5 文件 / 908 行）
├── Input/InputBase.cs              # 输入基类（37 行）
└── Tool/ToolConfig/                # 配置运行时模型（2 文件 / 143 行）
```

`Scripts/Editor/`：`Locale`（抓取工具）、`Core/UIMenu`、`Tool/ToolConfig`（配表读取/模板生成/自定义解析器）、`Tool/ModuleSplit`、`UI/FontArt`（字体美术编辑器）、`UI`（UIText/UIButton/Text3D 自定义 Inspector）。

> `UIManager/Resources/` 内置 `UICanvas.prefab`、`UIWindowBg.prefab`；`BettaFrameworkRoot.prefab` 在包根。

## 三、启动链路

```
启动场景挂 BettaFrameworkRoot.prefab
  └─ BettaFrameworkRoot.Awake()            [DefaultExecutionOrder(-100)]
       ├─ DontDestroyOnLoad(gameObject)
       └─ LocaleManager.Init()              # 读 BettaFrameworkConfig，加载默认语言

UIManager（SingletonMono）首次访问时 Awake()
  ├─ DontDestroyOnLoad
  ├─ Canvas.preWillRenderCanvases += OnPreWillRenderCanvases   # 屏幕适配钩子
  ├─ 冻结 Phone/Pad 资源变体判定（UtilsDevice.UseLegacyPadUIResourceVariant）
  ├─ ScreenResolution.Init(Portrait) + OrientationToPortrait()
  ├─ GetCanvas(UISortingOrderDefault=100)  # 默认 Canvas
  └─ 实例化 UIWindowBg（业务 Assets/Betta/Resources/UI/UIWindowBg 优先，缺失回退包内）

上层应用 Init 阶段
  └─ UIManager.Init(IImplementManager)     # IApplicationModule 生命周期桥接
       └─ EnsureScreenAdaptationRuntime()   # 订阅 UtilsNative 屏幕信号
```

关键约定：
- `BettaFrameworkConfig` 必须可被 `Resources.Load<BettaFrameworkConfig>("Config/BettaFrameworkConfig")` 命中。
- `UIManager` 是 `SingletonMono<UIManager>`，同时实现 `IUIManager` + `IApplicationModule`，通过 `RegisterImplement` 注入 `IImplementManager`。

## 四、复刻清单（分档）

| 能力 | 可复刻度 | 说明 |
|---|---|---|
| StateMachine / StateBase | **100%** | 纯 C#，169 行，零 Unity 依赖 |
| MessageDispatch | **100%** | 仅依赖 `BettaSDK.Singleton`，逻辑完整可抄 |
| Locale / LocaleAsset / LocaleManager | **95%** | 依赖 `ResourceHub`（SDK）、`UtilsEncryption`（SDK）、Newtonsoft、ProtoBuf；Resources 路径与字体资源需项目自备 |
| Expression 引擎 | **95%** | 纯 C# 编译器+执行器，依赖 ProtoBuf（`ProtobufSubTypeSpec` 多态注册）；可直接移植 |
| UIManager / UIWindow / UIBase / UICanvas | **90%** | 核心窗口栈可精确重建；**屏幕适配层依赖 `UtilsNative` / `UtilsDevice`（SDK 原生桥接）**，跨平台需对接原生尺寸回调 |
| UI 控件 / FontArt | 索引级 | UIText / UIButton / Text3D / UISafeArea / UITextArt 等，按需移植，不逐类展开 |
| Utils（Config 工具链） | 索引级 | `UtilsConfig` / `VerticalMergeRegistry` / `ConfigVerticalMergeWireUtil` 属配置覆盖体系，与 BettaSDK 配置管线耦合 |

> 平台桥接是本包唯一不可「纯抄」的部分：屏幕适配（`UtilsNative.CurrentWindowMetricsAvailable` / `ScreenChangeAvailable` / `TryBeginNextScreenChange`）与设备判定（`UtilsDevice.IsPadDevice` / `UseLegacyPadUIResourceVariant`）都落在 BettaSDK 的 Native 层，复刻时要么复用 BettaSDK，要么自建等价回调。

| `UISafeArea.cs` | `UISafeArea` + `BorderScale` | 安全区适配（配合 UIManager 屏幕适配） |
| `FontArt/UITextArt*.cs` | `UITextArt` + Template/Mesh 体系 | 字体美术（艺术字），Editor 端另有完整生成器 |

### 5.2 Expression 表达式引擎（`Expression/`，1200 行）

| 文件 | 关键类 | 职责 |
|---|---|---|
| `Compiler.cs` | `ExpressionCompiler` | 词法 `Tokenize` → 后缀 `ToPostfix`（运算符优先级表）→ `BuildNodes` 生成 `CompiledExpression` |
| `Define.cs` | `CompiledExpression` / `ExpressionNode` / `ConstantValue` / `ArrayValue` / `FunctionInfo` | 编译产物数据结构（节点/常量/变量/数组/函数表） |
| `Executor.cs` | `IVariableProvider` / `ExpressionRuntime` | 运行时求值 `Execute` / `ExecuteValue` |
| `DictionaryProvider.cs` | `DictionaryProvider : IVariableProvider` | 字典变量提供器 + 函数注册/调用 |

> 用途：配置驱动逻辑（如 UserLayer 表达式上下文）。`Define.cs` 内含 `ProtobufSubTypeSpec` 多态注册（`ArrayElementBool/Double/String`），是 Protobuf 子类型序列化的关键。

### 5.3 Utils 工具类（`Utils/`，索引级）

| 文件 | 关键类 | 职责 |
|---|---|---|
| `UtilsConfig.cs` | `UtilsConfig` | 配置读取/覆盖（`GetConfigOverrideSingle<T>`），配表覆盖机制核心 |
| `ConfigVerticalMergeWireUtil.cs` | `ConfigVerticalMergeWireUtil` | 纵向合并接线上游 |
| `VerticalMergeRegistry.cs` | `VerticalMergeRegistry` | JSON/Proto 合并回调注册（`RegisterJsonMerge` / `RegisterProtoMerge` / `TryMergeJson`） |
| `UtilsReflection.cs` | `UtilsReflection` | 反射辅助 |
| `UtilsInput.cs` | `UtilsInput` | 输入封装辅助 |

### 5.4 Editor 工具（`Scripts/Editor/`，索引级）

- `LocaleFetcher` / `LocaleHelper`：从 GoogleSheet 拉取多语言资源
- `Tool/ToolConfig`：配表读取、模板生成（`ConfigTemplate` / `ProfileTemplate` / `CodeBuilder`）、自定义类型解析器（`Array2dNumberParser` / `ExpressionParser` 等）
- `Tool/ModuleSplit`：模块拆分窗口
- `UI/FontArt`：字体美术生成器 + 构建校验（`FontArtBuildValidator` / `FontArtAssetGenerator`）
- `UI/UITextEditor` / `UIButtonEditor` / `Text3DEditor`（含 RTL 分支）：自定义 Inspector
