# BettaSDK 启动与生命周期

> 本文回答：SDK 从挂载到就绪经历了什么、由谁驱动、各 Hub 何时初始化、有哪些条件编译开关。
> 入口是挂在 `BettaSDKRoot.prefab` 上的 `BettaSDKRoot`（MonoBehaviour），用 Unity 生命周期逐帧驱动各 Hub。

---

## 一、入口 MonoBehaviour

`BettaSDKRoot` 是 SDK 的**唯一驱动源**，`DontDestroyOnLoad` 常驻。完整源码见下：

```csharp
public class BettaSDKRoot : MonoBehaviour
{
    public static Transform Root { get; private set; }

    public void Awake()
    {
        DontDestroyOnLoad(gameObject);
        Root = transform;
        if (!TryGetComponent<ProfileLifecycleSaveBehaviour>(out _))
            gameObject.AddComponent<ProfileLifecycleSaveBehaviour>();

        UtilsTime.Init();
        UtilsNative.Init();
        UtilsDevice.Init();
        PerformanceMonitor.Init();
        xasset.Logger.Loggable = false;

#if UNITY_6000_0_OR_NEWER
        Debug.developerConsoleVisible = false;
        Debug.developerConsoleEnabled = false;
#endif
#if MODULE_SRDEBUG
        SRDebuggerHelper.Init();
#endif
    }

    private void Start()
    {
        XAssetVersionManager.Initialize();   // 资源版本管理
    }

    private void Update()
    {
        var deltaTime = Time.deltaTime;
        UtilsTime.Update();
        ProfileHub.Instance.Update(deltaTime);
        PassportHub.Instance.Update(deltaTime);
        UserHub.Instance.Update(deltaTime);
        PerformanceMonitor.Update(Time.unscaledDeltaTime);
        ResourceHub.AutoRecycleUpdate(deltaTime);
    }

    private void OnApplicationPause(bool paused)
    {
        UtilsEvent.Send(new EventOnApplicationPause(paused));  // 广播暂停/恢复事件
    }

    private void OnDestroy()
    {
        PerformanceMonitor.Release();
    }

    public static void OnGameReady()
    {
        PassportHub.Instance.ReportReinstallOnGameReady();
        PerformanceMonitor.SetReportReady();
        RuntimeProtectionBI.TryTrackColdStartAbnormal();
    }
}
```

## 二、生命周期阶段

| 阶段 | 触发 | 动作 |
|---|---|---|
| 挂载 | `Awake` | 置 Root、挂 `ProfileLifecycleSaveBehaviour`、初始化 4 个 Utils + 性能监测、关 xasset 日志 |
| 首帧 | `Start` | `XAssetVersionManager.Initialize()` 资源版本管理 |
| 每帧 | `Update` | 驱动 `ProfileHub` / `PassportHub` / `UserHub` 的 `Update` + 性能监测 + 资源自动回收 |
| 切后台 | `OnApplicationPause` | 广播 `EventOnApplicationPause(paused)` |
| 销毁 | `OnDestroy` | `PerformanceMonitor.Release()` |
| 游戏就绪 | `OnGameReady()`（静态，业务层显式调用） | 重装上报 + 性能上报就绪 + 冷启动异常检测 |

### 关键点

1. **业务层需手动调用 `BettaSDKRoot.OnGameReady()`** —— SDK 不自动判断"游戏就绪"，这是接入方（玩法层）在首屏/登录完成后触发的唯一业务钩子。
2. **`Update` 里不驱动 `ServiceHub`** —— 第三方服务是挂到 `UtilsTimer`（见下），不是每帧 MonoBehaviour 驱动。

## 三、档案的"兜底保存"

```csharp
[DefaultExecutionOrder(32000)]   // 极晚执行，保证所有组件 OnApplicationPause 先跑完
internal sealed class ProfileLifecycleSaveBehaviour : MonoBehaviour
{
    private void OnApplicationPause(bool paused)
    {
        if (!paused) return;
        ProfileHub.Instance.SaveToLocalForLifecycle("save local on late application pause");
    }
    private void OnApplicationQuit()
    {
        ProfileHub.Instance.SaveToLocalForLifecycle("save local on late application quit");
    }
}
```

`DefaultExecutionOrder(32000)` 让它**最后**响应切后台/退出，兜底落盘玩家档案。

## 四、第三方服务初始化（ServiceHub.Init）

`ServiceHub` 本身不挂 MonoBehaviour，靠 `UtilsTimer.Instance.AddDelegate(Update)` 挂进帧循环。初始化流程：

```
ServiceHub.Init()
  ├─ ServiceConfig.Instance.Init()          # 读 JSON → 填 Configs 字典
  ├─ foreach Configs → switch(ServiceDefine) # 按配置名显式 new 对应 Service
  │    AppsFlyer / Firebase / Max / TA / Facebook / Google* / AIHelp
  ├─ 无配置服务直接建：Apple* / DeepLink / GooglePlay / GameService*
  ├─ ServiceMax?.Start()                     # Max 最后启动（依赖其他服务就绪）
  ├─ UserSetOnce(app_version_first / app_build_first)
  ├─ UserSet(device_id / client_os / app_version / app_build)
  ├─ SetSuperProperties(app_build)
  └─ Best.HTTP.HTTPManager.UserAgent = UtilsDevice.GetUserAgent()
       UtilsTimer.Instance.AddDelegate(Update)   # 挂进帧循环
```

> 完整工厂机制见 [[03-KNOWLEDGE/底层框架/BettaSDK/第三方服务-ServiceHub|第三方服务-ServiceHub]]。

## 五、Hubs 聚合初始化

`Hubs` 是几个 Hub 的**统一初始化门面**（非全部 Hub，只收编需要显式启动的那几个）：

```csharp
public sealed class Hubs : Singleton<Hubs>
{
    private bool _initialized;
    public void Init()
    {
        if (_initialized) return;
        _initialized = true;
        AdHub.Instance.Init();          // 广告
        HapticsHub.Instance.Init();      // 振动
        UtilsAppVersion.StartCheck();    // 版本检查
        // ServiceNotifications 推送权限申请（默认注释，可后移）
    }
}
```

## 六、条件编译宏速查

### 自有代码的关键宏

| 宏 | 作用 |
|---|---|
| `PASSPORT_GOOGLE` | 启用 Google 登录（`ServiceGoogle` 字段与 `case ServiceDefine.Google`） |
| `PASSPORT_APPLE` | 启用 Apple 登录（`ServiceApple` 字段与 `CreateService<ServiceApple>`） |
| `PASSPORT_FACEBOOK` | 启用 Facebook 登录 |
| `GameCenter` / `GoogleGameService` | 启用游戏服务（成就/排行榜，`ServiceHub.GameService.cs`） |
| `MODULE_SRDEBUG` | 启用 SRDebugger（`SRDebuggerHelper.Init()`） |
| `DISABLE_SRDEBUGGER` | 禁用 SRDebugger |
| `OBFUZ` | 启用混淆（Obfuz.Runtime） |
| `ENABLE_LOGGING` / `PROFILE_LOG` | 日志开关 |

### 内嵌第三方宏（非自有，勿混）

`BESTHTTP_*`（BestHTTP）、`NETCOREAPP*` / `NETSTANDARD*` / `NET5_0+`（.NET 目标框架）、`UNITY_*`（Unity 版本）、`WITH_UNITASK`（UniTask）等 1052 处 `NETCOREAPP2_1_OR_GREATER` 主要来自内嵌 BestHTTP/xasset。

## 七、初始化时序总览

```
挂载 BettaSDKRoot.prefab
  └─ Awake: UtilsTime/Native/Device + PerformanceMonitor + xasset 日志
  └─ Start: XAssetVersionManager.Initialize
  └─ （业务层调用）Hubs.Instance.Init()      # Ad/Haptics/版本检查
  └─ （业务层调用）ServiceHub.Instance.Init() # 第三方服务建连
  └─ （业务层调用）ProfileHub.Instance.Init(...)  # 玩家档案
  └─ （业务层调用）PassportHub.Instance.Login(...) # 登录
  └─ （业务层调用）BettaSDKRoot.OnGameReady()     # 就绪上报
```

> 注意：`BettaSDKRoot` 只负责**骨架初始化 + 帧驱动**，`Hubs`/`ServiceHub`/`ProfileHub`/`PassportHub` 的**业务初始化仍需接入方显式调用**，不存在"挂上 prefab 就全自动跑"的魔法。
