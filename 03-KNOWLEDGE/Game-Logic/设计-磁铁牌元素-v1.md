# 磁铁牌元素方案 v1

<!-- kc:KC-20260903-001-magnet-card-design:A1 -->

## 已确认需求

- 新增一种可在关卡内放置与试跑的特殊牌，暂称 `Magnet`；参考金牌或火箭牌的局内载体与开局改牌路径。
- 当前选择编辑器右侧障碍栏**直接放置**磁铁牌，固定坐标且不做组绑定；`MagnetGroupCount` 的开局随机改牌路径保留为未启用的备选机制。
- 玩家点击任一磁铁牌后：点击牌立即进入手牌区（Bar），磁铁效果再将另外两张磁铁牌吸至 Bar，随后通过 `BarChanged → BarMatch` 完成三消。
- “点击牌飞往 OverBar”与“随机触发一次”均为 2026-09-03 初稿笔误，已于 2026-09-04 更正；不可再作为实现或验证口径。
- 当前在 `level_trial` 分支的 LevelEditor + Trial 验证；不新建独立运行时或固定实验关文件。

## 当前设计口径

| 维度 | 方案 | 依据 / 说明 |
| --- | --- | --- |
| 元素载体 | 独立、可点击的特殊 `Tile`，而非覆盖普通牌的 `Effect` | 它需要自身点击、专属动画和三张联动状态；火箭是最近的开局改牌参照。 |
| 放置方式 | 当前由编辑器右侧障碍栏直接放置 | 固定位置、无组绑定；开局按组改牌不是当前路径。 |
| 点击后逻辑 | `MagnetPull`：点击牌与另外两张磁铁牌进入 Bar，随即触发匹配消除 | 复用多牌入栏视图流程（`MultiTilesAdd`），动画结束后广播 `BarChanged` 触发 `BarMatch`。 |
| 随机边界 | 当前直接放置无开局随机；若恢复组数改牌机制，随机仅决定开局转化结果 | 点击不随机，且需要届时定义组关联与回放记录。 |
| 关卡数据 | 当前由编辑器障碍类型 `BlockType=5210` 放置 | `MagnetGroupCount` 配置仅为保留的备选路径。 |

## 待确认事项与验证边界

1. 先在 Unity Trial 验证：编辑器面板显示、手动放置、点击一张后恰好三张进入 Bar 并触发匹配、占位图标与输入时序均符合预期。
2. 火箭、闪电、风车、局内磁铁、自动匹配、撤回等道具命中磁铁牌时的行为尚未定义。
3. 录像/重连、机器人与正式局 DDA 支持尚未纳入当前 Trial 最小闭环。
4. 若恢复“每关组数 / 开局改牌”路线，需另行确定：候选不足时的降级、三张的组绑定、随机记录与回放语义。
