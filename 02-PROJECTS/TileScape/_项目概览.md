# TileScape 项目概览

## 基本信息

- **项目类型**: 消除类游戏 (Match-3 / 方块消除)
- **引擎**: Unity (C#)
- **代码仓库**: `D:\TileScape`
- **项目关系**: 类似 TileMatch 的独立项目，玩法主干为 **TileV2**（TileMatch 二代），从旧项目迁移演化而来
- **架构**: 分层架构（Packages 底层子模块 + Game/Module/Interface 三层 + TileV2 玩法域）
- **配置序列化**: Protobuf (.bytes) + ScriptableObject (.asset)
- **程序集管理**: asmdef / asmref
- **依赖**: BettaSDK / BettaFramework / Betta.Interface / UniTask / xasset

## 核心模块

### 玩法（TileV2，统一命名空间 Game.TileV2.Scripts.*）
- 核心逻辑位于 `GameCore/Logic/GameLogic`：Board/Tile/Match/Bar 实体 + Services + ECA Behaviours
- 火箭牌：`Module/LevelRocket/`
- 障碍：`Config/LevelObstacleConfig/` + `Services/BlockerGuaranteeService`
- 死局判定：`TileMatchGameLogic.Deadlock.cs` + `Module/InLevelDDA/InevitableDeathJudge`
- 牌局生成：`Module/LevelTileType/Strategy/`、`Module/LevelDepth/TileDepthComputer`
- DDA 动态难度：`Module/InLevelDDA/InLevelDDA.cs`（V1/V2）

### 编辑器工具（Game/TileV2/Editor）
- LevelEditor — 关卡编辑器（Core/Views/Config/Excel/Utils）
- LevelBot — 关卡自动化测试 Bot（支持 CI 批量跑关）
- TileTypeEditor — 牌型/表现编辑

### 公共基础设施
- BettaSDK（SDK 中枢）/ BettaFramework（UI 框架 UIManager）/ Betta.Interface（接口契约）
- xasset（资源管理）/ UniTask（异步基座）
- TileMatch.DomainEvent（领域事件总线）/ Assets/Framework/UIFrame（本地 UI 框架）
- HotUpdate（GameMain.cs 热更入口）/ Betta.AOT（IL2CPP 引导）

## 配置层

- 运行态数据：LevelData（纯 C# 数据类）
- 静态配置：LevelConfig（SO asset）+ 表配置（protobuf，Excel 源 `TileV2/ExcelConfig/*.xlsx`）
- 远程配置：DynamicLevelConfig（JSON 下载）
- 玩家配置：Profile（BettaSDK）+ UserLayer（上下文系统）

## 工作空间

- 项目自带规则/技能体系：`.cursor/rules` + `.cursor/skills`（AGENTS.md 索引）
- Docs/ 目录含 50+ 篇迁移/设计文档（TileScape_*、TileV2_* 系列）
