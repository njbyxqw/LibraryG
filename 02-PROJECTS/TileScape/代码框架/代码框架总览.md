# TileScape 代码框架总览

> 本文档梳理 TileScape（类似 TileMatch 的独立消除类项目）的整体代码框架，作为代码导航索引。
> 核心路径以 `Assets/Game/TileV2` 为主，统一命名空间 `Game.TileV2.Scripts.*`。

## 一、程序集 / 模块划分

### 底层子模块（Packages/，git submodule）

| 程序集 | 位置 | 职责 |
|---|---|---|
| **BettaSDK** | `Packages/BettaSDK` | SDK 服务中枢：Hub（Ad/Audio/Haptics/Passport/Profile/Purchase/Resource）、ServiceHub、Singleton、PerformanceMonitor；内嵌第三方包：xasset、BestHTTP、StompyRobot、AppIconChanger、各渠道 SDK |
| **BettaFramework** | `Packages/BettaFramework` | UI 框架：UIManager（UIBase/UICanvas/UIWindow/UIWindowConfig/UIScreenChangeCoordinator）、UI 控件（UIText/UIButton/安全区/RTL）、MessageDispatch、Input、SceneState、Locale |
| **Betta.Interface** | `Packages/BettaInterface` | 跨模块接口契约：Audio、Cameras、Flow、Haptic、Input、Item、Logger、PlayerInfo、Purchase、RedDot、Resource、Tutorial、UI、UserLayer 等 |
| **UniTask** | `Packages/com.cysharp.unitask` | 异步框架（含 UniTask.DOTween 扩展） |

### 游戏层程序集（Assets/ 下）

| 程序集 | 路径 | 职责 |
|---|---|---|
| **TileMatch** | `Game/TileV2/Scripts/Entry` | 组合根/入口（TileMatch.cs），引用全部玩法程序集 |
| **TileMatch.Config** | `.../Scripts/Config` | 配置/静态数据层（Tile/Level/Obstacle/TableConfig，纯数据） |
| **TileMatch.DomainEvent** | `.../Scripts/DomainEvent` | 领域事件总线（DomainEventBus.cs） |
| **TileMatch.Logic.Interface** | `.../GameCore/Logic/Interface` | 逻辑层接口与枚举（IEntity/ILogicService/LogicEventType…） |
| **TileMatch.Logic.GameLogic** | `.../GameCore/Logic/GameLogic` | ★ 核心消除/棋盘逻辑（实体、Service、ECA Behaviours、Bot、机制模块） |
| **TileMatch.Logic.LevelLogic** | `.../GameCore/Logic/LevelLogic` | 关卡逻辑（LevelData/LevelState/TileMatchLevelLogic） |
| **TileMatch.Application** | `.../GameCore/Application` | 应用层（TileMatchApplication、ActionInvoker、AsyncEventLoop） |
| **TileMatch.View** | `.../GameCore/View` | 表现层（TileMatchViewController、Views、Headless 无头模式、UnityMock） |
| **TileMatch.Interface** | `.../Scripts/Interface` | 玩法对外接口/DTO（仅依赖 Game.Interface、Betta.Interface） |
| **TileMatch.Profile** | `.../Scripts/Profile` | 玩家存档（仅依赖 BettaSDK） |
| **TileMatch.Tutorial** | `.../Scripts/Tutorial` | 新手引导 |
| **TileMatch.UI** | `.../Scripts/UI` | 局内 UI 面板（UIGamePanel/UIWinPanel/UIRevivePanel 等） |
| **TileMatch.GameRecord** | `.../Scripts/GameRecord` | 对局记录/回放 |
| **TileMatch.Util** | `.../Scripts/Util` | 工具库 |
| **TileMatch.Editor** | `Game/TileV2/Editor` | 编辑器工具（LevelEditor/LevelBot/TileTypeEditor），仅 Editor 平台 |
| **TileShared.Util / TileShared.GameRecord** | `Game/TileShared/Scripts` | 共享工具与记录 |
| **Game.Interface** | `Assets/Interface` | 模块接口契约（Tile/UI/Item/Purchase/Route/Reward…） |
| **Betta.Module** | `Assets/Module` | 模块实现大程序集（Activity/Shop/Mail/UserLayer/UI… 40+ 模块目录） |
| **Betta.AOT** | `Assets/Betta.AOT` | AOT/IL2CPP：GameRoot.cs、ApplicationLoading、BettaEventAgent、Strip |
| **HotUpdate** | `Assets/Scripts` | 热更入口（GameMain.cs 属此程序集，引用全部模块） |

### 依赖关系（自底向上）

```
BettaSDK / BettaFramework / Betta.Interface / UniTask / xasset / DOTweenModule / TMP
   └─ TileShared.Util ──┬─ TileMatch.Config
        └─ TileMatch.DomainEvent / TileMatch.Logic.Interface / TileMatch.Logic.LevelLogic
              └─ TileMatch.Logic.GameLogic ──┐
        ┌─────────────────────────────────────┤
   TileMatch.View ── TileMatch.Application ── TileMatch.Game（facade）
        └─ TileMatch.GameRecord / TileMatch.Util / TileMatch.Profile / TileMatch.Tutorial
              └─ TileMatch（Entry）── TileMatch.UI ── TileMatch.Editor
```

> 跨玩法平级之间只依赖接口程序集（Game.Interface/Betta.Interface），实现靠注入；TileV2 玩法内部可直接依赖实现程序集。

## 二、Assets 目录架构

```
Assets/
├─ Game/                    # 玩法域
│  ├─ TileV2/               # ★ 主玩法
│  │  ├─ Scripts/Config/    # 配置数据（Tile/Level/LevelObstacle/TableConfig）
│  │  ├─ Scripts/GameCore/  # ★ 核心：Application / Game / Logic(Interface·GameLogic·LevelLogic) / View
│  │  ├─ Scripts/{Entry,UI,Profile,Tutorial,GameRecord,DomainEvent,DataCenter,DynamicLevelConfig}
│  │  ├─ Editor/            # ★ 关卡编辑器/机器人/牌型编辑器
│  │  ├─ Config/ ExcelConfig/ Define/ Res/ XAsset/   # SO 配置、xlsx、资源
│  ├─ TileShared/           # 共享 Util/GameRecord
│  └─ Merge/                # 合成玩法资源
├─ Module/                  # 40+ 功能模块（Activity,Ad,Shop,Mail,UserLayer,Profile,UI,HomeHub…）
├─ Interface/               # Game.Interface 接口契约
├─ Framework/Runtime/UIFrame# 本地 UI 框架（Panel/Runtime）
├─ Betta/                   # 本地定制：Obfuz 脚本、Assembly 配置、XAsset 构建
├─ Betta.AOT/               # IL2CPP/AOT 引导
├─ Editor/Obfuz/            # 混淆构建自动化
├─ Scripts/                 # GameMain.cs 入口 + HotUpdate
├─ 3rd/                     # DOTween / Spine / ParticleEffectForUGUI
└─ GameSystem/ Res/ Resources/ StreamingAssets/ SubAssets/ Settings/
```

## 四、数据 / 配置层

- **LevelData（运行态）**：`GameCore/Logic/LevelLogic/Data/LevelData.cs`，纯 C# 数据类
- **LevelConfig（SO）**：`Scripts/Config/Level/LevelConfig.cs` + `Config/LevelConfig/` 目录下 .asset；障碍配置 `Config/LevelObstacleConfig/`
- **Tile 配置**：`Scripts/Config/Tile/TileConfig.cs`、`Config/TileConfig/`（TileV2 根 Config 目录）
- **表配置（protobuf/二进制）**：`Scripts/Config/TableConfig/ConfigManager.cs`、`Levels.cs`；Excel 源 `TileV2/ExcelConfig/*.xlsx`
- **动态关卡配置**：`Scripts/DynamicLevelConfig/`（远程下载 JSON 配置）
- **玩家配置**：`Scripts/Profile/`（TileMatch.Profile，存档走 BettaSDK.Profile）+ `Module/UserLayer/`（UserLayer 上下文系统，入口注册 `Entry/TileMatchUserLayerContextContributor.cs`）

## 五、公共基础设施

- **xasset**：资源管理（AB 构建/加载），Runtime 在 `Packages/BettaSDK/Packages/xasset/Runtime/`；构建配置 `Assets/Betta/XAsset/`、各模块自带 XAsset 目录
- **UniTask**：全项目异步；⚠️ 强约束：禁用 `UniTask.Delay`/`WaitUntil`，延迟用 DOTween `DOVirtual`，等待用 `UniTask.Yield(PlayerLoopTiming.Update, ct)`
- **BettaFramework**：UI 管理（UIManager）、消息派发（MessageDispatch）、本地化（Locale）、场景状态（SceneState）
- **自定义框架**：`Assets/Framework/Runtime/UIFrame`（本地 UI 面板框架）、`TileMatch.DomainEvent`（DomainEventBus + Module/BettaEventAgent 运行时桥接）、`Assets/Interface`（模块接口契约层）

## 六、编辑器扩展

- **LevelEditor**（`Game/TileV2/Editor/LevelEditor/Script/`）：关卡编辑（Core/Views/Config/Excel/Utils），含 LevelConfigEditController、BoardView、LayerView、LevelListView
- **LevelBot**（`.../LevelBot/Script/`）：关卡自动化测试 Bot（BotRunner、LevelBotCommandLine、LevelBotJenkins、ILevelBotStrategyFactory），支持 CI 批量跑关
- **TileTypeEditor**（`.../TileTypeEditor/Script/`）：牌型/表现编辑（Application/Domain/Presentation/Systems）
- **关卡数据资产**：`Editor/LevelConfig/Levels*`（按策划分组：CYK/GDF/GXL/SRH/QA）
- **混淆构建**：`Assets/Editor/Obfuz`（ObfuzBuildAutomation、ObfuzSymbolArchive 等）

## 七、注意事项

- ⚠️ 用户级 skill `tilev2-code-index` 的 references 索引（concept-map.md / tilev2-structure.md）为旧路径（`TileV2/Scripts/Behaviours/`），实际应为 `TileV2/Scripts/GameCore/Logic/GameLogic/Behaviours/`，引用时以本文档为准
- 项目内 `.cursor/skills/tile-*` 技能引用的路径均为新布局（GameCore/Logic/GameLogic），可直接使用
- 项目根目录 `Doc/`、`Docs/` 含大量迁移记录与设计文档，索引见 [[参考/Docs文档索引|Docs 文档索引]]
