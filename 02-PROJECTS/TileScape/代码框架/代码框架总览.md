# TileScape 代码框架总览

> 本文档梳理 TileScape（类似 TileMatch 的独立消除类项目）的整体代码框架，作为代码导航索引。
> 核心路径以 `Assets/Game/TileV2` 为主，统一命名空间 `Game.TileV2.Scripts.*`。
> **2026-08-20 扩充**：追加第八~十二章文件级检索索引（关键类→路径、模块明细、View/编辑器/Bot/ECA 结构），检索时优先看第八~九章。

## 一、程序集 / 模块划分

### 底层子模块（Packages/，git submodule）

| 程序集 | 位置 | 职责 |
|---|---|---|
| **BettaSDK** | `Packages/BettaSDK` | SDK 服务中枢：Hub（Ad/Audio/Haptics/Passport/Profile/Purchase/Resource）、ServiceHub、Singleton、PerformanceMonitor；内嵌第三方包：xasset、BestHTTP、StompyRobot、AppIconChanger、各渠道 SDK |
| **BettaFramework** | `Packages/BettaFramework` | UI 框架：UIManager（UIBase/UICanvas/UIWindow/UIWindowConfig/UIScreenChangeCoordinator）、UI 控件（UIText/UIButton/安全区/RTL）、MessageDispatch、Input、SceneState、Locale |
| **Betta.Interface** | `Packages/BettaInterface` | 跨模块接口契约：Audio、Cameras、Flow、Haptic、Input、Item、Logger、PlayerInfo、Purchase、RedDot、Resource、Tutorial、UI、UserLayer 等 |
| **UniTask** | `Packages/com.cysharp.unitask` | 异步框架（含 UniTask.DOTween 扩展） |

## 四、数据 / 配置层

- **LevelData（运行态）**：`GameCore/Logic/LevelLogic/Data/LevelData.cs`，纯 C# 数据类
- **LevelConfig（SO）**：`Scripts/Config/Level/LevelConfig.cs` + `Config/LevelConfig/` 目录下 .asset；障碍配置 `Config/LevelObstacleConfig/`
- **Tile 配置**：`Scripts/Config/Tile/TileConfig.cs`、`Config/TileConfig/`（TileV2 根 Config 目录）
- **表配置（protobuf/二进制）**：`Scripts/Config/TableConfig/ConfigManager.cs`、`Levels.cs`；Excel 源 `TileV2/ExcelConfig/*.xlsx`
- **动态关卡配置**：`Scripts/DynamicLevelConfig/`（远程下载 JSON 配置）
- **玩家配置**：`Scripts/Profile/`（TileMatch.Profile，存档走 BettaSDK.Profile）+ `Module/UserLayer/`（UserLayer 上下文系统，入口注册 `Entry/TileMatchUserLayerContextContributor.cs`）

## 五、公共基础设施

- **xasset**：资源管理（AB 构建/加载），Runtime 在 `Packages/BettaSDK/Packages/xasset/Runtime/`；构建配置 `Assets/Betta/XAsset/`、各模块自带 XAsset 目录
- **UniTask**：全项目异步；⚠️ 强约束：禁用 `UniTask.Delay`/`WaitUntil`，延迟用 DOTween `DOVirtual`，等待用 `UniTask.Yield(PlayerLoopTiming.Update, ct)`
- **BettaFramework**：UI 管理（UIManager）、消息派发（MessageDispatch）、本地化（Locale）、场景状态（SceneState）
- **自定义框架**：`Assets/Framework/Runtime/UIFrame`（本地 UI 面板框架）、`TileMatch.DomainEvent`（DomainEventBus + Module/BettaEventAgent 运行时桥接）、`Assets/Interface`（模块接口契约层）

## 六、编辑器扩展

- **LevelEditor**（`Game/TileV2/Editor/LevelEditor/Script/`）：关卡编辑（Core/Views/Config/Excel/Utils），含 LevelConfigEditController、BoardView、LayerView、LevelListView
- **LevelBot**（`.../LevelBot/Script/`）：关卡自动化测试 Bot（BotRunner、LevelBotCommandLine、LevelBotJenkins、ILevelBotStrategyFactory），支持 CI 批量跑关
- **TileTypeEditor**（`.../TileTypeEditor/Script/`）：牌型/表现编辑（Application/Domain/Presentation/Systems）
- **关卡数据资产**：`Editor/LevelConfig/Levels*`（按策划分组：CYK/GDF/GXL/SRH/QA）
- **混淆构建**：`Assets/Editor/Obfuz`（ObfuzBuildAutomation、ObfuzSymbolArchive 等）

## 十二、ECA 行为系统（GameLogic/Behaviours/）

| 目录 | 内容 |
|---|---|
