# 道具无限使用测试

## 使用

等待 Unity 编译完成，重新进入 Play 模式以注册命令。打开 GM → Common → **添加无限道具（测试）**，默认道具 ID `15`、追加小时 `24`；点击执行后重新打开战前面板核对无限状态。支持 1–720 小时，期间不限使用次数，不减少普通库存。重复执行按现有 Unlimited 叠加策略处理。

测试结束在同一页执行 **清除道具无限状态（含已有时长）**，默认 ID `15`。该操作清除指定道具的全部 Unlimited 效果（包括已有正常奖励时长），保留普通数量。时长也会自然到期。

## 磁铁配置结论

| 标识 | 值 | 含义 |
|---|---:|---|
| Item ID | 15 | 新战前磁铁库存 |
| Reward ID | 86 | 发放磁铁数量的奖励行，grantType=1 |
| PropType | 24 | 局内业务道具枚举 Magnet |
| TileType | 5210 | 棋盘磁铁牌类型 |
| 初始奖励 | [86, 3] | iteminit 行 ID=8，新存档初始三份磁铁 |

旧魔法棒 Item ID=6，旧局内提示/磁铁道具 Item ID=13，均不同于新增 ID=15。`0dcc8f10f` 新增 MAGNET 常量及 ItemCfg/Reward/Init 配置。json~ 是导出对照，运行配置默认读取 bytes；本次未改配置，也未重新发放初始奖励。

## 代码入口与影响

- TS `Assets/Module/Item/Scripts/Logic/ItemSystem.GM.cs`：注册、校验、发放和清除，受 `(DEBUG || DEVELOPMENT_BUILD) && MODULE_GM` 门控。
- 发放：`ItemChangeDataExtend(itemId, 0, Unlimited, hours * 3600)` → `AddItem` → `EffectStore` → 状态通知。使用 Ignore，不上报此次测试发放的 report_item。
- 清除：ItemSystem owner 将指定道具 Unlimited 效果置为到期，走已有清理和通知流程；不会清空其他道具或数量堆叠。
- 使用：战前选择 → `TileMatchDataCenter.TryConsumeStartResources` → `ItemSystem`；`ConsumePlanner` 命中 Unlimited 后满足消耗请求，不扣普通数量。
- 效果写入现有 ProfileItem.Effects，随项目存档保存流程持久化，重启不会自动清除；本次没有修改存档格式。
- Item/Reward/Init 源码与配置位于 `Assets/Module/Item/Config/`；业务常量在 `Assets/Game/TileV2/Scripts/Interface/DTOs/ItemIdConst.cs`。
