# Merge Joy · 活动入口与主界面

## 1 目标与范围

玩家从首页进入一周一期的Joy活动，在弹窗内看到主题、剩余时间、主链目标和棋盘。此模块负责入口及页面组织；投放、BP、进度奖励和结束资格由对应模块定义。

## 2 当前基础与改动

| 功能 | 迁移版基础 | 本版要求 |
|---|---|---|
| 首页入口 | 已有活动入口与生命周期接入 | 按Joy排期和开放门槛显示，进入当前一期；正式配置替换调试长期开启配置 |
| 主界面 | 已有活动面板与弹窗流程 | 改为Joy式弹窗，四周保留压暗背景 |
| 页面内容 | 阶段、图鉴、倍率等迁移版内容 | 展示圣诞主题、倒计时、主链进度、6×8棋盘、底部操作；保留帮助、关闭和BP入口 |
| 旧入口 | 图鉴、资源购买／兑换、倍率等 | 本版不显示，也不通过旧红点、推荐弹窗或教学进入这些功能 |

## 3 页面与操作

| 区域／操作 | 内容与结果 |
|---|---|
| 标题与倒计时 | 表达本期活动身份与剩余时间，与首页入口和BP的本期身份一致 |
| 主题区 | 首套圣诞主题，提供BP入口；装饰不遮挡按钮或棋盘 |
| 进度区 | 展示主链已解锁记录、后续目标与礼包，具体见模块04 |
| 棋盘区 | 6列×8行，完整展示当前盘面；不保留独立5×5教学盘 |
| 底部区 | 根据待投放内容、活动时间和终奖状态显示气泡或Play，具体见模块05 |
| 帮助 | 说明打关获取、投放、合成、两层覆盖和目标奖励；关闭帮助返回当前盘面 |
| BP入口 | 打开本期BP，关闭后恢复当前棋盘；不重新初始化活动 |
| 主窗关闭 | 在期且终奖未领时保存返回；终奖后或到期后的关闭走模块08最终退出流程 |

正常关闭重进恢复当前棋盘、资源、解锁及领奖记录，不重发开场赠送。到期不沿正常参与入口直接重建棋盘；允许重入的收尾条件见模块08。

## 5 验收

- 达到开放门槛且在活动期内可进入；不同入口指向同一期。
- 主界面各区域在目标设备完整显示，点击区域不被装饰或相邻控件覆盖。
- 帮助／BP打开关闭不丢失盘面，不重发开场资源。
- 图鉴、倍率、兑换及独立资源商店无入口、红点、推荐弹窗或教学残留。
- 普通关闭、终奖后关闭、到期关闭分别进入正确流程。

## 6 实现顺序建议

1. 确认P06及主界面区域稿，列出保留与关闭的入口。
2. 完成圣诞主面板和各入口状态，接入模块04／05／06／08。
3. 验收正常参与、弹窗返回、到期入口及设备适配。
