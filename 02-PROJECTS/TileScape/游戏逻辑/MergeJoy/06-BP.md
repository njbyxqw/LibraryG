# Merge Joy · BP

## 1 目标与范围

BP根据指定主链物品的首次解锁，提供免费与付费两轨奖励。它有自己的目标完成、购买权益和领奖状态，不等同于主界面进度条，也不要求交出棋盘上的目标物品。

本模块覆盖入口、档位进度、奖励领取、购买后补领及结束补领条件。活动整体结束顺序由模块08定义，主链解锁事实由模块03提供。

## 3 页面必须提供的信息

| 页面区域 | 必要内容与操作 |
|---|---|
| 顶部 | BP身份／剩余时间、关闭入口，与本期活动一致 |
| 目标列 | 目标物品图标、解锁进度0/1或1/1；能区分未完成与已完成 |
| 免费轨 | 每档奖励品类、数量／适用时长，以及未达成、可领取、已领取状态 |
| 付费轨 | 同上，同时表现未购买锁定；锁定不隐藏可获得的奖励内容 |
| 购买区 | 实际售价与购买入口；已购买、不可售、购买处理中需有可区分状态 |
| 列表 | 档位超出可视区时能够查看完整内容；页面重开显示真实进度与领取记录 |

本版逐档展示领奖资格；具体按钮形式由UI稿确定，不增加任务提交、工具消耗或另一套BP经验值。活动收尾中的BP提醒见模块08，本模块不另新增自动弹窗玩法。

## 4 BP进度怎样增加

- 一档配置一个主链目标，首次解锁该物品后从0/1变为1/1。
- 达成时不扣除棋盘物品；物品之后升级或消失，目标仍为已完成。
- 只统计真实解锁，不因为出现更高等级而补齐中间目标。仍受限制的棋子被揭出时不完成目标。
- 重复合成同等级不重复推进或重置领奖；奖励链物品不推进BP。
- 主链进度礼包自动发放，与BP目标完成同时发生时仍分别反馈；BP不会因主链礼包发放而自动标记已领取。
- 竞品默认10档、对应主链Lv.2～11，只作参考；本版目标及档位数由P04确定。

## 5 目标、权益与领取状态

以下状态按**每档、每条轨道**分别判断。表中“可领取”均以本期BP仍允许处理为前提，最终退出后的补领走模块08。

| 目标 | 免费奖励 | 付费奖励 | 玩家可做什么 |
|---|---|---|---|
| 未完成 | 不可领 | 无论是否购买均不可领 | 查看目标及奖励；商品可售时可购买BP，但购买不完成目标 |
| 已完成、未领取 | 可领 | 未购买则锁定；已购买则可领 | 按对应轨道领取已具备资格的奖励 |
| 已领取 | 显示已领，不可重复 | 各自显示领取记录 | 可查看奖励信息，不再到账 |
| 已完成后才购买 | 免费轨状态不改变 | 此前已完成且未领取的档位变为可领 | 补领本期已达标付费奖励，无需重新合成目标 |

免费与付费领取互不覆盖：领取免费奖不领取付费奖，购买也不重置免费领奖。连续点击、关闭重开和重复回调不能重复发奖；界面进度与实际权益、到账状态应一致。

## 6 购买与奖励到账

| 情况 | 要求 |
|---|---|
| 未购买且商品可售 | 显示实际售价并允许发起购买 |
| 商品未接入或不可售 | 不可购买，不模拟成功或提前发权益 |
| 正在处理购买 | 不将付费奖励提前标为可领；重复点击不得重复交付权益 |
| 成功获得本期权益 | 展示已购买，开放已达成档位的付费领奖 |
| 取消／失败 | 保留未购买状态，不授予权益、不发奖，可按实际可售状态再次操作 |
| 恢复订单／重复回调 | 识别原订单所属期，不能重复发奖或误授下一期权益 |

活动投放资源奖励到账后增加模块05的基础投放数量；普通奖励进入对应游戏资源。数量、限时奖励时长、预览与实际到账一致。若P04选用棋盘物品奖励，应明确其物品和落盘／暂存方式，不可把它当成普通资源到账。

截图价格不是TS售价，两套竞品付费奖励配置不能叠加使用；本版只交付选定的一套正式方案。

## 7 关闭、收尾与结束补领

- 普通关闭BP只返回棋盘，不重置目标、权益或领取状态。
- 未最终退出、仍在有效BP页面时，手动领取按该页面资格执行，可领取配置中的活动资源；不提前套用结束过滤。
- 最终退出自动补领：免费轨需目标已完成且未领取；付费轨还需已购买本期权益。
- 自动补领剔除活动基础投放资源。若同档同时含普通奖励与活动资源，只补其中普通奖励；不将被剔除资源折算为其他奖励。
- 只剩活动资源奖励或没有合格奖励时，不展示空补领列表，但允许继续后续结算。
- 未购买的付费奖不补；未完成目标的奖不补；已领取奖励不重发。
- 过期后是否仍可购买按商品可售配置执行，不能因棋盘仍留场而延长销售时间。

## 8 配置与美术交付清单

| 输入 | 必须明确的内容 |
|---|---|
| 档位表（P04） | 顺序、目标物品、免费奖、付费奖；普通奖励与活动资源分别列明 |
| 商品表（P04） | 正式商品标识、平台SKU、实际价格、本期权益、可售起止与合法测试条件 |
| 展示素材 | 目标图标、奖励图标、免费／付费轨、锁定、可领、已领、购买状态和关闭按钮 |
| 文案 | 目标进度、购买、不可售、支付结果及结束补领说明 |

若设计增加多数量目标、购买即送独立礼包或新奖励类型，需另列需求，本稿不默认加入。

## 10 验收用例

| 用例 | 预期结果 |
|---|---|
| 目标未解锁先购买 | 权益成功，未达标奖励仍不可领 |
| 首次解锁目标 | 该目标1/1；免费可领，付费按是否购买判定 |
| 物品继续合成／重新合出 | 目标不回退，已领不重发 |
| 先达成多档再购买 | 对应未领付费奖可补领，无需重做目标 |
| 直接得到高阶、低阶未解锁 | 仅真实解锁目标完成，低阶仍0/1 |
| 连点领奖／关闭重进 | 只到账一次，领取状态正确 |
| 取消、失败、恢复与重复订单 | 不错误授予、重复发奖或串到下一期 |
| 免费／已购／未购三种账户结束 | 仅补各自有资格且未领取的普通奖励 |
| 纯资源BP／混合BP结束 | 纯资源不弹空列表；混合只补普通部分 |
| 资源奖励手动领取与结束补领 | 前者在有效页面正常到账，后者过滤活动资源 |

## 11 实现顺序建议

1. 逐项评审BP01～BP06，先补P04商品、目标与奖励表及页面状态稿。
2. 接入模块03解锁事实，完成双轨领取、模块05资源到账和商品权益。
3. 与模块08联调手动领取、最终退出补领、空结果及中断防重。
4. 用上述状态组合验收，分别回填业务、支付和界面结果。
