# Merge Joy · 教学与主题资源

## 1 目标与范围

让玩家在正式6×8棋盘中理解投放、合成、揭盖和目标奖励，交付完整的首套圣诞表现。本模块说明教学内容与各功能所需资源；具体步骤时机、文本和素材清单需随配置／设计稿交付。

## 2 当前基础与修改

迁移版已有3组16步教学、帮助、多语言与主题资源，包含冰冻／火焰等内容。本版复用引导及中断恢复能力，重新组织Joy步骤；旧16步不能直接当作本版已交付教学。

## 3 教学内容

| 内容 | 玩家应理解或完成的动作 | 对应模块 |
|---|---|---|
| 资源来源 | 打主线关卡可获得基础投放次数；开场赠送与盘面预置是不同内容 | 05 |
| 投放 | 点击气泡放入物品，理解数量减少和空格限制 | 05、02 |
| 合成 | 拖入同类同级物得到下一级，不要求提交物品 | 03 |
| 两层覆盖 | 邻接合成揭开全覆盖，受限棋子需同物合成才能解除 | 02 |
| 主链目标 | 解锁物品推进进度条，首次到礼包节点获得奖励 | 04 |
| BP与奖励区别 | 帮助说明BP目标完成与主链礼包不同，BP免费／付费按各自资格领取 | 06 |

教学使用同一张正式棋盘，不切换5×5教学盘。按P02验证初始空位、赠送数量和底物等级支持步骤完成。BP说明是否安排为强引导需在具体教学稿中确定，本稿不据此新增强制购买步骤。

正常关闭或中断后按实际教学进度恢复；旧冰冻／火焰教学不再触发。已有旧教学完成记录不能直接导致Joy新增必要教学被跳过，具体触发条件在P06列清。

## 4 主题与资源交付

| 功能模块 | 需提供的内容与状态 |
|---|---|
| 01 主界面 | 圣诞入口、主题装饰、主窗、倒计时、帮助、关闭与BP入口 |
| 02 棋盘 | 地格、边框、全覆盖、露出后受限表现；正常／受限清晰区分 |
| 03 主链 | P01选定各级物品的名称与图标，可辨识等级成长 |
| 04 进度条 | 已解锁图标、未解锁剪影、礼包节点、已发状态、预览与最终奖励展示 |
| 05 投放 | 气泡、下一物品图标、角标、Play、满盘提示 |
| 06 BP | 目标、双轨奖励、锁定／可领／已领、购买状态、实际价格展示 |
| 07 奖励物 | 两条奖励链各等级素材、可兑现奖励信息 |
| 08 收尾 | 终奖反馈、BP补领、退出损失确认、结算／补偿信息 |
| 教学与帮助 | 手势／提示、对应目标、说明文案及项目支持语言版本 |

所有正式素材按本版内容配置交付，不要求旧主题／旧地图全部开放。使用项目现有字体与多语言体系，不能出现旧功能文案、缺图、缺字或错误点击区。

## 6 进度与验收

需求内容已拆出；圣诞资源、步骤稿、多语言文案与P01／P02／P06配合关系待交付。现有引导系统可复用，Joy步骤和状态绑定的实现进度待程序回填；尚无完整Joy教学及设备视觉验收结果。

验收覆盖：首次教学能完成；关闭重进可恢复；存在旧教学记录时仍按新触发规则处理；无图鉴、冰冻、火焰、倍率、换盘教学；所有模块资源与正式配置对应；设备上文字、图标、点击区完整可用。

## 7 实现顺序建议

1. 按各模块确定素材与文案清单，先交P01／P02支持的教学流程稿。
2. 完成圣诞主题及引导目标绑定，保留中断恢复。
3. 依次验收首次、重进、旧记录以及目标设备上的各模块页面。
