# 音效实际使用与未接入项审计

> 历史静态审计。配置或资源存在不等于运行时已接入；后续改动须重新核验当前代码。

## 已确认的关键实际使用

- 通用 UI 点击直接使用 `Assets/Module/Audio/Clip/Common/SFX_btn_click.wav`，不是 `SFX_uiClick` 配置 ID。
- 开局实际播放 `SFX_level_begin_TilesDown`，不是 `SFX_level_begin`。
- 手套使用 `SFX_useProp_crane`、风车使用 `SFX_useProp_shuffle`；+1 道具使用 `SFX_addone_use`，不是 `SFX_useProp_extraSpace`。
- 失败面板使用 `SFX_levelFail`；局内连消固定播放 `SFX_tile_match01`，未实现 `02-05` 的递进音阶。
- 局内 BGM 当前只有 `SFX_level_bgm_1-4` 选择分支。

## 功能存在但专属音效未接入

| 优先级 | 项目 | 静态结论 |
|---|---|---|
| P0 | `SFX_useProp_magnet` | AutoMatch 流程存在，但没有专属播放点。 |
| P0 | `SFX_useProp_undo` | RevertLastAdd 实际执行，但道具表现默认分支不播放专属音效。 |
| P0 | `SFX_tile_match02-05` | 配置/资源存在，当前仅播放 `SFX_tile_match01`。 |
| P1 | `SFX_level_Win_Welldone`、`SFX_level_success` | WellDone / 通关流程存在，未找到专属播放调用。 |
| P1 | `SFX_panel_pop`、`SFX_progress_add`、`SFX_popup` | 配置与资源存在，未找到自动播放入口。 |
| P1 | `SFX_level_Fail_NoMoreSpace`、`SFX_level_Fail_TryAgain` | 当前失败流程未区分专属音效。 |
| P2 | `SFX_level_bgm_5`、`SFX_shellbox2_*` | 无当前选择/使用分支；后者资源亦缺失。 |
