# 磁铁战前道具：表现流程与调参

分支：`feat-tileMagent`。日期：2026-10-29。

本次范围是开场发放、磁铁牌花色定位、局内表现参数。保留原有选牌、三消、存档、回放、Headless 规则。以下流程来自静态代码，视觉效果尚需 Unity PlayMode 确认。

## 实现顺序建议

1. Step1：核对 `MagnetProp`、换牌 Action/Invoker、`SourceMatchBatchExecutor` 和磁铁 View，确认表现完成后才通知战前道具流程继续。已完成。
2. Step2：将磁铁表现配置挂到 `TileMatchViewController`，提供开场、连线、目标牌、入栏和消除参数。普通牌仍取原默认参数。已完成。
3. Step3：在磁铁来源的换牌表现前播放魔法棒和三条飞行光线，光线到达后换牌并播放命中效果；取消时停止等待与飞行动画。已完成。
4. Step4：定位花色和消除特效；收到新图后保留图片 meta/GUID 替换，核对透明边距和显示尺寸。定位已完成，替图待提供图片。

## 现有玩法与职责

- `MagnetProp.Use`：从棋盘普通牌中选择同花色三张，优先选择可点击牌较多的花色；排除 Candy、Joker、锁定牌、序列牌。只从棋盘选，不从 Bar/OverBar 发放。
- `ChangeTileTypeAction`：逻辑先将选中牌改成 `TileType.Magnet = 5210`，保留同一 TileData 身份；表现随后重建牌 View 并转移附着 EffectView。
- `ChangeTileTypeActionInvoker`：等待表现完成，才发出 `PrePropUsed.Success`，继续后续开场流程。没有候选牌时沿用现有跳过路径。
- `Magnet.json`：一条命，三张匹配。点击要求 Bar 至少有一个空位。可洗牌，不进入普通花色池/DDA，不作为旧魔法棒复制目标。
- `SourceMatchBatchExecutor`：点击磁铁后，从棋盘和 OverBar 找另外两张同类磁铁，优先可点击目标，也能吸出被遮挡的目标；不选锁定目标，不借用已经在 Bar 的磁铁。凑不足一组时不会执行整组吸取。
- 整组先在逻辑层锁定、移出原容器并入栏；表现完成后发送 `BarChanged` 触发三消。动画参数不参与选牌或随机数。
- 运行时动画、Tween 和临时提层由表现层持有；新增参数仅属于表现配置，不写 Profile，也不改变录制数据。

## 开场表现

`战前选择磁铁 → 选中三张同花色牌 → 魔法棒出场/音效 → 等待 0.6 秒 → 三条光线同时飞行 0.4 秒 → 命中后换成磁铁牌 → 停留 0.15 秒 → 开场流程继续`

魔法棒按现有布局策略锚定 Bar 或 OverBar，支持位置偏移与整体缩放。默认粒子存活上限 2 秒，可能在开场流程继续后短暂保留尾效；实际寿命也受粒子本身停止状态控制。存活上限至少覆盖发射、飞行和换牌停顿。缺少魔法棒资源时记录错误并继续换牌，缺少光线时保留相应等待；退出关卡时取消动画。

## 局内表现

`点击一张磁铁 → 本张开始飞入 Bar，同时另外两张提层/显现/放大 → 等待 0.12 秒 → 从本张的当前画面位置向另外两张发射光线 → 光线飞行 0.35 秒 → 命中特效 → 另外两张飞入 Bar → 所有入栏完成 → 三张缩小消除/破碎`

默认另外两张一起飞；可通过 `HitToFlightDelay` 加命中停顿，通过 `TargetFlightInterval` 形成先后节奏。入栏后回弹沿用原异步尾动画，未增加“必须回弹结束才三消”的等待。

## 调参入口

打开 `Assets/Game/TileV2/Res/Scene/TileMatchGameV2.prefab`，选根节点 `TileMatchViewController`，展开 **磁铁表现（开场发放 / 局内吸取 / 入栏消除） → Magnet Presentation**。

新增序列化字段使用代码默认值初始化。编辑 Prefab 可保存调参；Play 模式下改实例只是临时预览，需要另行保存参数。特效路径由每关粒子池缓存，修改资源路径后重新进入关卡验证。所有时间单位为秒，位置为世界坐标，缩放为倍率。

配置定义：`Assets/Game/TileV2/Scripts/GameCore/View/Config/Views/ViewActions/AutoMatch/MagnetMatchPresentationConfig.cs`。

### 开场 Grant

| 参数 | 默认 | 作用 |
|---|---:|---|
| WandPrefabPath | MagicWand/Prefab/eff_wand.prefab | 魔法棒资源，字段中为完整项目相对路径 |
| AnimationName / SoundName | animation / SFX_magicwand_use | Spine 动画、出场音效；音效留空可关闭 |
| WandSpeed / WandScale | 1.3 / 1 | 动画速度、整体尺寸；调速度后同步核对发射时机 |
| WandOffsetX / WandOffsetY | 0 / 0 | 相对 Bar/OverBar 锚点的偏移 |
| WandDuration | 2 | 魔法棒粒子存活上限，至少覆盖发射和换牌过程 |
| BeforeBeamDelay | 0.6 | 魔法棒出现到发射的等待 |
| LineTravelTime / LineEase / LineScale | 0.4 / Linear / 1 | 发放光线飞行时长、缓动、尺寸 |
| HitScale / HitDuration | 1 / 1 | 换牌命中特效尺寸（乘牌尺寸）、存活上限 |
| AfterTransformDelay | 0.15 | 换牌后继续开场流程前的停顿 |

### 局内与共用特效

| 参数 | 默认 | 作用 |
|---|---:|---|
| LinePrefabPath / HitPrefabPath | eff_wandLine / eff_wandTile | 开场和局内共用的光线/命中 Prefab 完整相对路径 |
| EffectSortingOrder | 5000 | 特效绝对排序；目标牌在原棋盘排序上增加此值 |
| SourceBeamDelay | 0.12 | 点击本张到向目标发射的等待 |
| LineTravelTime / LineEase / LineScale | 0.35 / OutSine / 1 | 局内光线时长、缓动、尺寸 |
| HitDuration / HitScale | 1 / 1 | 局内命中特效存活上限、尺寸 |
| TargetScale / TargetScaleTime / TargetScaleEase | 1.12 / 0.12 / OutSine | 另外两张相对原尺寸的放大倍率、时长、缓动 |
| HitToFlightDelay | 0 | 光线命中到目标开始入栏的间隔 |
| TargetFlightInterval | 0 | 目标牌之间开始入栏的间隔；0 为同时 |
| BreakEffectDuration / BreakEffectOrderOffset | 1 / 200 | 消除破碎粒子存活上限、排序偏移 |

粒子颜色、粒子数量、发射曲线、材质和贴图属于上述 Prefab 的 ParticleSystem/材质参数，直接编辑相应资源。Spine 姿态和挥棒轨迹属于动画资源。

### 入栏/消除 Tile Animation

磁铁使用自己的 `TileAnimation` 配置，普通牌继续使用原默认配置；修改这里不会调快或调慢普通牌。

| 参数 | 默认 | 作用 |
|---|---:|---|
| addToBarRate / addToBarMaxDuration | 15 / 0.27 | 入栏移动速度、时长上限 |
| flightScaleMultiplier / landingScaleMultiplier | 1.5 / 0.75 | 飞行放大、落点收缩尺寸（相对 Bar 牌尺寸） |
| flightScaleUpRatio | 0.5 | 放大占飞行时间的比例，0–1 |
| flightScaleUpEase / flightScaleDownEase | OutQuad / InQuad | 飞行缩放与落点回弹使用的缓动 |
| flightMoveEase | Linear | 路径推进缓动 |
| flightControlPointX / flightControlPointY | 0.618 / 0.328 | 入栏曲线路径中间控制点相对起终点的比例，建议先在 0–1 内调 |
| landingBouncePeakMultiplier | 1 | 落点回弹峰值 |
| landingBounceUpDuration / landingBounceDownDuration | 0.12 / 0 | 落点回弹两段时长 |
| adjustBarItemPositionMoveTime | 0.14 | Bar 内重新排位时间 |
| matchInBarDuration / matchShrinkEase | 0.07 / InQuad | 三消缩小时间、缓动 |
| moveToBarScaleTime / moveToBarMoveTime | 0.12 / 0.15 | OverBar/返回棋盘的缩放、位移时间 |
| moveToOverBarPropMoveTime | 0.3 | 手套将磁铁移到 OverBar 的时间 |
| moveToOverBarSelectedTileSortingOrder / moveToOverBarMaxRaisedSortingOrder | 100 / 6000 | 手套提层参数 |

`TileAnimation` 复用了现有牌动画配置结构，因此 Inspector 也会显示下列非本流程主调参数：

- `addToBarMinDuration`：旧近距离公式中会代数抵消，不是有效的最小时长限制。
- `addToBarScaleTimeThreshold`、`matchInBarBreakEffectDelay`：正常 GameView 当前不读取，调它们不会改变磁铁效果。
- `lastTile*`：仅 `BarAddType.Click && IsLastTile` 分支读取；磁铁整组吸取走 `AutoMatch`，不走该分支。

## 花色替换

- 图片：`Assets/Game/TileV2/Res/Game/GameCore/Texture/Tiles/block_5210.png`，当前 256×256，单 Sprite，中心 Pivot，Pixels Per Unit=280。
- 引用：`Assets/Game/TileV2/Res/Game/GameCore/Prefab/TileView/TileMagnet.prefab` → `VisualTransform/Icon` 的 SpriteRenderer。
- Icon 本地偏移 `(0, 0.12, 0)`，缩放 `(1, 1, 1)`。牌底使用另一张 `block_bg.png`。
- 给一张透明背景图片即可继续替换。优先保留 `block_5210.png.meta` 的 GUID 和导入设置；若图片分辨率变化，按有效图形大小调整 PPU 或图标尺寸，避免在牌上忽大忽小。
- 磁铁消除资源为 `Assets/Game/TileV2/Res/Game/GameCore/ParticleMatch/Particle/block_5210_Particle.prefab`，花色图片的直接引用检索目前只发现 `TileMagnet.prefab`。消除粒子使用独立材质，换花色图不会自动重做破碎特效。

## 调整建议

以下只是待观看确认的建议，未写入默认值。

| 目标 | 建议第一组试值 | 理由 |
|---|---|---|
| 吸取更利落 | LineTravelTime=0.25、HitToFlightDelay=0.04、TargetFlightInterval=0.05 | 缩短光线等待，用很短的命中停顿和错峰保持可读性 |
| 减少跳动 | TargetScale=1.08、flightScaleMultiplier=1.25、landingScaleMultiplier=0.9 | 当前连续经历 1.12 倍提示和入栏 1.5 倍放大，可能过于跳跃 |
| 三消更清晰 | matchInBarDuration=0.10 | 当前 0.07 秒缩小很快，略放慢可留出辨认时间 |
| 强化磁力感 | 替换 LinePrefabPath / HitPrefabPath | 当前是魔法棒光线和闪光，换成磁场连线、吸附亮点更贴题 |

建议先只调时间，再调缩放，最后换特效，以便判断每次调整的贡献。开场发放可能选中被遮挡牌，需专门观看光线终点的可读性，再决定是否增加开场显现/提层（本次保持原棋盘遮挡关系）。
