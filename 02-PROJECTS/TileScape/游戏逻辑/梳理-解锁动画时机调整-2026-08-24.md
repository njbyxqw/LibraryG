# 解锁动画时机调整

> 本文只记录已确认的表现链路与相对时间。`T+0` 均为各自流程实际开始节点，不把上游面板打开、进度动画或教程步骤的等待时间混入动画本体。

## 1. 主界面普通关：关卡按钮脉冲

### 运行时路径

`HomeSceneState.OnEnter` → `EnterHomeReady` → Home Flow → `FlowItemHomeLevelButtonPresentation` → `TabBarHome.ClearPulse`。

### 已实施时序

| 相对时间 | 表现 |
|---|---|
| T+0.00s | 按钮脉冲开始，缩放上行。 |
| T+0.23s | 缩放上行结束，开始缩放回落。 |
| T+0.36s | 播放按钮 Effect 粒子。 |
| T+0.40s | **切换关卡号**。 |
| T+0.46s | 缩放回落结束，脉冲 Sequence 完成。 |

- **实现**：`Assets/Module/UIMain/Script/TabPage/TabBarHome.ClearPulse.cs`。
- **结论与注意事项**：关卡号从原本依赖完整脉冲结束的时机，改为 Sequence 内 `T+0.40s` 回调；按钮缩放总时长仍为 `0.46s`，Effect 仍为 `T+0.36s`，没有修改总时长或粒子时机。

## 2. 结算面板：新障碍解锁飞行

### 运行时路径

`UIWinPanel.OnOpen` → `WinPanelView.Play` → `BeginUnlockVisuals` → `EnterAnimatedUnlockLandingState` → `PlayNewElementLandingEffect`。

### 触发前置

- 仅当 `WinPanelProgressData.TriggerUnlockReveal` 为真：存在预览元素、完成关卡达到预览元素的 `EndId`，且未抑制解锁展示。
- 解锁飞行相对面板打开的开始时间为：无进度条变化时 `T+0.35s`；有进度条变化时 `T+1.20s`（开场淡入 `0.35s` 后接进度动画 `0.85s`）。下表以飞行开始为 `T+0`。

### 已实施时序

| 相对时间 | 表现 |
|---|---|
| T+0.00s | 创建旧进度图标副本并开始沿 Catmull-Rom 弧线飞向新障碍位置；图标同时放大至 `2.5×`。旧进度/奖励区域同时淡出 `0.35s`。 |
| T+0.55s | 飞行抵达；销毁飞行副本，显示新障碍；**播放 Effect 下的全部粒子**。 |
| T+0.70s | 经过 `0.15s` 展示停留后，新障碍解锁主/副文案同时淡入 `0.20s`。 |
| T+0.90s | 解锁文案淡入结束；后续 Continue 淡入 `0.35s`。 |

- **实现**：`Assets/Game/TileV2/Scripts/UI/UIWinPanel/WinPanelView.cs`。
- **Prefab**：`Assets/Game/TileV2/Res/UI/UIWinPanel/UIWinPanel.prefab`；`Effect` 下包含本地 `effect` 粒子和嵌套 `Assets/Module/Common/Effect/Prefab/Effect_RewardItem_Light.prefab`。
- **结论与注意事项**：本次将新障碍显示和所有落点粒子从原先飞行结束后再等待 `0.15s`，提前至飞行抵达的 `T+0.55s`；原 `0.15s` 改为文案淡入前的展示停留，因此后续文案与 Continue 节奏保持不变。Prefab 当前另有将两套 Effect 缩放由 `1.0` 调为 `1.2` 的视觉修改，不影响时序。

## 3. 局内道具：教程解锁飞向按钮

### 运行时路径

`TileTutorialPopupPresenter` 发送 `TileItemFly` → `TileGamePanelPropController.OnTutorialItemFly` → `TileMatchFlyBridge.OnTutorialItemFly` → `IFlySystem.FlyToTarget(Track 1)` → 完成回调 → `TileGamePanelPropButton.PlayTutorialUnlockedEffect`。

### 当前时序

| 相对时间 | 表现 |
|---|---|
| T+0.00s | 教程弹窗确认后发出 `TileItemFly`；道具图标开始沿 Track 1 贝塞尔路径飞向局内道具按钮。 |
| T+0.00–0.24s | 飞行图标由 `1.0×` 放大至 `1.8×`。 |
| T+0.24–0.48s | 飞行图标保持 `1.8×`。 |
| T+0.48–0.80s | 飞行图标缩小至 `0.75×`。 |
| T+0.80s | 飞行完成回调：解除按钮锁定、刷新图标、激活 `Eff_UI_GoalCollect`；按钮同时开始 `DOPunchScale(0.1, 0.5s)`。 |
| T+0.80–1.80s | `Eff_UI_GoalCollect` 的单次粒子播放约 `1.0s`；按钮缩放在 T+1.30s 结束。 |

- **飞行实现**：`Assets/Module/Fly/Engine/Track/UIFlyTrack1.cs`，`FlyTime = 0.8f`、`Ease.InOutCubic`。
- **按钮实现**：`Assets/Game/TileV2/Scripts/UI/UIGamePanel/TileGamePanelPropButton.cs`。
- **Prefab**：`Assets/Game/TileV2/Res/UI/UIGamePanel/Skill.prefab` 的 `Root/AnimRoot/Eff_UI_GoalCollect`；当前粒子为单次、`lengthInSec: 1`。
- **结论与注意事项**：局内道具链路当前仅完成定位，未做时机调整；飞行完成回调是特效与按钮缩放的共同开始节点，不存在额外固定延时。
