# 二合活动迁移与改造需求草案

将 MT（TileMatch）的二合活动迁移到 TS（TileScape），根据 TS 的周目标定位进行改造。玩家通过打关获取活动资源，消耗体力释放基础合成物，在棋盘上合成升级，以主链推进阶段、支链提供奖励或辅助，逐步获得活动奖励。

本篇跟进 TS 产品规则、功能取舍和程序交付状态。MT 的原始规则、数值和源码入口见 [[02-PROJECTS/TileScape/游戏逻辑/背景-MT二合活动迁移|MT 二合活动迁移背景]]。

## 2 核心循环与命名

### 2.1 核心循环

**打关获取活动资源 → 消耗体力释放基础合成物 → 棋盘移动与合成升级 → 主链推进阶段、支链提供奖励或辅助 → 领取奖励。**

当前释放口径为“消耗体力，释放基础合成物”。打关如何获得体力、每次消耗与产出数值尚未定稿。基础合成物是棋盘上的合成起点；不将它与体力混称为同一种余额资源。

### 2.2 统一术语

| 名称 | 当前口径 |
|---|---|
| 体力 | 用于发射器释放基础合成物的活动资源 |
| 代币 | 初稿对活动资源的上位称呼；具体规则优先使用“体力”或具体物品名称，是否另设代币待后续需求明确 |
| 发射器 | 初稿中的“释放口”；展示所需资源及余额，点击后向棋盘释放基础合成物 |
| 基础合成物 | 发射器释放到棋盘、用于继续合成的起始物品；具体类型和初始等级待定 |
| 合成链 | 一组能够沿既定关系逐级合成的物品 |
| 主合成链／主链 | 承担阶段推进目标的合成链 |
| 支链 | 提供奖励或辅助的合成链 |
| 奖励物品链 | 可合成升级，并能领取奖励的一条物品链；对应初稿“合成物奖励链” |
| 物品等级 | 同一条合成链中合成物的升级层级 |
| 阶段推进 | 活动目标随主链成长而推进；具体分段、达标和领奖条件待定 |
| 主合成链切换 | 当前主链升满后，进入下一条主合成链 |
| 棋盘切换 | 更换承载合成操作的棋盘；与主链切换是否绑定待定 |
| 活动 BP／BattlePass | MT 的任务驱动、免费与付费双轨奖励系统 |
| 发射倍率 | 发射器的倍率档位，作为后续参考能力；本轮未确定采用规则 |

MT 代码对体力存在 `Power`、`Energy` 两种命名；产品讨论统一称“体力”。技术接入时再按接口语义对位，不在需求阶段决定全局代码改名。

## 3 已确认的功能与表现

### 3.1 发射器

- 展示代币样式与剩余数量，当前释放消耗按体力理解。
- 点击一次，触发一次向棋盘释放基础合成物的操作。
- 提供点击反馈和资源不足反馈。
- 发射倍率可参考 MT 实现方案，具体是否采用及何时接入另行细化。

一次操作的费用、产物数量、等级、落点及满盘处理统一见 P02、P03，不将“释放一次”直接写成任何具体倍率规则。

### 3.2 棋盘

- 使用 `n×m` 矩形棋盘，具体行列数待定。
- 承载合成物的移动、合成与消除等操作。
- 由多条合成链构成玩法内容；主链承担阶段推进，支链提供奖励或辅助。

换位、非法拖动、消除含义、满盘和链尾物品处理见 P03、P04。

### 3.3 合成成长与阶段变化

已确认两类成长变化：

1. **同一棋盘内的物品等级升级。** 通过合成提高当前主合成链的物品等级。
2. **主合成链切换。** 当前主链升满后，进入下一条主合成链。

主链切换可能伴随棋盘切换，是否换盘仍待定。物品等级、奖励节点、主链切换和棋盘切换分别描述，不能默认“每升一级必领奖”或“每换主链必换盘”。

主链数量、满级判定、阶段达标口径及切换过程中的物品处理见 P04、P05、P06。

### 3.4 进度展示

- 展示当前主合成链各级物品的样式及成长进度。
- 已解锁物品为彩色，未解锁物品为黑色剪影。
- 展示阶段奖励与大奖。
- 支持左右拖拽滑动。

解锁依据、进度与领奖状态的对应关系、默认展示位置及切链后的内容更新见 P05、P07。

### 3.5 三类奖励

| 奖励形式 | 已确认含义 |
|---|---|
| 合成物奖励链／奖励物品链 | 一条可合成并领取奖励的物品链 |
| 合成物阶段奖励 | 随合成成长和阶段推进设置的奖励，具体节点待定 |
| 大奖 | 活动目标中的大奖，达成条件和发放时机待定 |

主链与支链描述链路职责，三类奖励描述奖励形式；不能据此推定每条支链都是奖励物品链。合成物阶段奖励与大奖的具体物品、数量、领取条件，以及是否消耗合成物，统一见 P07。

### 3.6 活动 BP

BP 沿用 MT 的概念：通过任务推进，提供免费奖励与付费奖励两条轨道。初稿“阶梯制代币购买”的表述以此澄清为准，不作为另建阶梯购买系统的要求。

任务内容、奖励、付费权益、展示和领取规则在 P08 中细化。

### 3.7 装饰与主题资源

背景图、棋盘、代币、合成物样式组成同一套装饰资源，后续可按主题替换。首套主题及资源范围见 P10。主题替换是否同时改变合成链内容、棋盘布局或数值，尚未确定。

### 3.8 基础活动流程

需要纳入后续调研和设计的范围包括：Icon 状态、首次引导、帮助界面、弹窗规则及到期挽留。

当前只确认这些流程需要梳理；入口状态、引导步骤、帮助内容、弹窗触发、完成与到期分支尚未定稿，见 P09、P11。
