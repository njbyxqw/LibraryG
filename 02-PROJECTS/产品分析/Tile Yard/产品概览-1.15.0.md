# Tile Yard 产品概览（1.15.0）

Tile Yard 是以叠层牌三消为核心、庭院装修为长期目标，并叠加通行证、竞赛、收集进度和广告／内购的休闲产品。本次优先研究关内道具、障碍及连续滑动取牌，详见[[02-PROJECTS/产品分析/Tile Yard/游戏逻辑/关内道具障碍与滑动操作-1.15.0|关内专题]]。

## 身份和来源

| 项 | 样本事实 |
|---|---|
| 名称／发行标识 | Tile Yard: Matching Game；Google Play 显示 BPA Games，开发者主体 BEST PLACE APPS LTD |
| 包名／版本 | `com.bestplaceapps.tileyard`；1.15.0／9872 |
| 包组成 | 主 APK＋`config.arm64_v8a.apk`，无单独 OBB |
| 引擎 | Unity 2022.3.62f3；IL2CPP；玩法程序集 `TYLib.dll` |
| 证据范围 | 包内教程、本地化、布局、UI 对象、类型／方法及选定 ARM64 指令；没有实机流程／线上配置／广告实播 |

官方商店提供的产品介绍支持“三消与庭院装修”的定位，公开标注广告与应用内购买。抓取页的更新时间与用户样本不相同，商店页不作为 1.15.0 代码身份来源。[Google Play 官方产品页](https://play.google.com/store/apps/details?id=com.bestplaceapps.tileyard&hl=en)。不以页面上的评分、下载量推断收入、留存或当前版本质量。

## 产品结构

| 层 | 已发现内容 | 证据状态 |
|---|---|---|
| 核心玩法 | 点选牌入暂存槽，三张同类消除，清空棋盘；槽满失败；支持持续触摸移动辅助续收同类牌 | 教程＋部分原生逻辑核对 |
| 关内变化 | 冰、链条、可入槽石／固定石、百叶窗、黏连双牌、问号牌、槽内饼干；关内奖励牌 | 类型＋布局＋关键消费者；部分细节待实机 |
| 长期成长 | 庭院／场景装修，建筑奖励，地图与多个场景主题 | 包内对话、UI、Builder 类型；实际场景顺序未验 |
| 经济 | 星星、钻石、体力、道具与无限时道具等 | 字段、教程、本地化；当前汇率和发放量未验 |
| 周期与竞赛 | Seaside Pass、Sea Treasure、Tree of Gifts、Tileball、Daily Bonus、Competition／Clan 相关模块 | 包内文案／界面／类型；不能据此认定当前全部开放 |
| 商业化 | 去广告、首购、连锁礼包、存钱罐、通行证、道具补给及 Videometer 看广告进度 | 商店声明＋包内 UI／文案／SDK；价格、频控和曝光顺序未验 |

### 装修货币的口径差异

商店介绍写通关赚 coins 装修；本包 `Dialogues_en` 的建造不足提示明确使用 stars，`Builder`／`BUILDING_WIDGET_PRICE` 和星星相关组件同在。**本版初步按星星推进建造理解**，实际扣除和到账尚未实机核对；不把公开宣传中的 coins 直接套为本版经济规则。

### 关卡内容规模

`data.unity3d` 中导出 3,241 个 TextAsset，其中 2,990 个为 `level-数字` 唯一命名布局，文件编号 11–3050，并不连续；另有教程、机制样例、动态模板等。本次解析了 3,215 份 JSON 布局。文件编号不等于实际玩家关卡号，不能直接称“有 3050 个可玩主线关卡”，也不能用最小文件号认定障碍解锁等级。

## 初步产品判断

- 主线通过牌面遮挡、暂存槽压力和障碍状态组织决策；道具分别作用于后悔、重排、自动有效动作、槽位回退和容量。
- 滑动取牌提高凑齐同类牌的操作效率。已检查的普通牌移动路径有同色和槽内计数限制，保留玩家主动选择下一组牌的动作；特殊牌存在单独例外。
- 装修承接主线产出，活动叠加主线目标。具体回调、排期、解锁和付费转化路径需要各自核对，当前只建立模块地图。

以上为产品结构判断，没有玩家行为数据或经济效果数据，不评价商业成绩。后续优先做关内交互验证，再展开外围系统。
