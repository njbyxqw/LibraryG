# 产品分析资源目录规范

> [!important] 双层结构
> 产品分析的逻辑、框架、证据结论和路径索引保存在 `02-PROJECTS/产品分析/`；XAPK/APK、解包文件、图片、动效、音频、反编译产物和运行时采集保存在 `/Users/dean/LibraryG/06-PRODUCT-ASSETS/`。资源根目录属于本机大文件区，已加入 Git 忽略，不随知识库提交。

## 固定目录

```text
06-PRODUCT-ASSETS/
└── <ProductName>/
    └── <Version>/
        ├── 00-Package/               原始 APK、XAPK、IPA 或安装包
        ├── 01-Decoded/               解包、反编译资源与引擎原始数据
        ├── 02-Art/                   图片、图集、动效、Prefab 等导出物
        ├── 03-Audio/                 音效、音乐及导出报告
        ├── 04-ReverseEngineering/    类结构、IL2CPP、调用和指令证据
        └── 05-Runtime/               授权范围内的运行时截图、日志和抓取结果
```

## 命名规则

- 产品目录使用稳定英文产品名，不带版本，例如 `TileKingdom`。
- 版本单独成层，例如 `1.58`；同一产品的新版本不得覆盖旧版本。
- 原始包保留产品、版本和来源标识；其他目录按内容类型命名，不重复产品名。
- 工具和跨产品复用脚本不放进单个产品资源目录，继续维护在其共享工具位置。
- 每个产品版本必须在 `02-PROJECTS/产品分析/<产品>/` 保留资源路径索引，并注明本地、远端、静态和运行时证据边界。
