# Merge Joy 详细内容与配置参考

本表用于 TS Joy 修改需求评审。数值来自 Piggy Kingdom Android 2.7.3／203 包内默认配置，行为结合同构建托管 IL；用户秋季截图仅用于对应界面。它不是当前线上所有账号的配置，也不是 TS 最终配置。主链等级、奖励内容和数值先完整列出，TS 另行配置。

完整资源、方法体及新增边界见 [[02-PROJECTS/产品分析/PiggyKingdom/活动/MergeJoy/README|资源与逻辑入口]]；[音乐／秋季图册](资源图册-2.7.3.html)包含273张选用Sprite。下表保留数值评审用途，终奖留盘、BP资源过滤与固定补偿按规则主档第8节阅读。

## 1 资源来源与底部按钮

| 项目 | 核对结果 |
|---|---|
| 开场赠送 | CheckAndOpenNextScene 初始化2份活动资源；此外棋盘底行预置两件受限的一级物品，不能混算为同一余额 |
| 主线打关 | 成功奖励通过 TryReceiveLevelReward(num) 增加活动资源；模板奖励类型42，按难度倍率开启，已核上游按胜利结算、默认Difficulty加Buff_Add；难度起点1／3／5还可被关卡表与Buff改写，不能视为线上固定产量 |
| BP | 免费轨共50份；资源版付费轨共200份。混合奖励版付费轨不提供同样200份资源，见下表 |
| 盘面成长 | 解覆盖露出预置棋子；合出高阶主链产生奖励链棋子。增加可操作物品，不增加同等数量的基础投放资源 |
| 满盘暂存 | 奖励物品无空位时进入暂存，不是额外赠送来源 |
| 倍率／自然恢复／兑换／现金资源商店 | 已核 Joy 主界面、资源写入方法和33份相关默认配置，没有发现这些入口或定时恢复路径。商品93是BP，不是体力商店；这支持该包默认 Joy 不开放这些功能。外部礼包、远端新增配置及当前线上账号仍未全覆盖 |

底部将待投放内容集中在一个气泡：有暂存物时优先取暂存末项，没有暂存物则消耗1份资源生成主链一级物品，成功落入随机空格。角标为暂存件数＋活动资源数，图标为下一件暂存物或主链一级物品。两者都为0时隐藏气泡；活动时间尚有剩余且未领取最终奖时显示 Play。无空位时不扣资源、不移除暂存物。

证据：MergeminiGameView_Asm.OnShelf／UnShelveItem／UpdateShelveInfo（0x06001548／1569／156a），MergeGame.UnShelveItem／ConvertCoinToDefaultItem（0x06001e17／1e18），MergeDataModelBase.CheckAndOpenNextScene／TryReceiveLevelReward（0x060011d4／11ba）。全程序集资源写入方法与配置扫描边界见原始目录的 merge-joy-review-20261124/supply-audit.json。

| Lv.2 | 10102 | 10103 | 无 | 无 |
| Lv.3 | 10103 | 10104 | 无 | 无 |
| Lv.4 | 10104 | 10105 | 无 | 无 |
| Lv.5 | 10105 | 10106 | 无 | 无 |
| Lv.6 | 10106 | 10107 | 无 | 无 |
| Lv.7 | 10107 | 10108 | 60001×1、70001×1 | 无 |
| Lv.8 | 10108 | 10109 | 60001×1、70001×2 | 有 |
| Lv.9 | 10109 | 10110 | 60001×2、70001×1、70002×1 | 有 |
| Lv.10 | 10110 | 10111 | 60001×1、60002×1、70001×2、70002×1 | 有 |
| Lv.11 | 10111 | 10112 | 60001×3、60002×1、70001×2、70002×2 | 有 |
| Lv.12 | 10112 | 链尾 | 60001×3、60002×2、70001×4、70002×2 | 有 |

奖励棋子60001～60005为金币链Lv.1～5，70001～70005为道具链Lv.1～5。60005兑现100金币；70005按配置7个等权100条目抽取1项，候选为锤子、拳套、局内火箭、骰子各1，或彩球／炸弹／开局火箭各15分钟。此处1/7是当前候选池内单次抽取概率，不是主链掉落率。奖励物品不足空位时进入暂存。

## 3 进度条礼包

礼包对应主链Lv.8～12，首次解锁时按已解锁记录防重；物品继续合成或重复合出同等级不会重复获得首次奖励。界面提供礼包预览，末级进入最终奖励流程，替代该分支的普通等级发奖，不将末级配置奖与最终奖重复相加。奖励配置如下：

| 主链等级 | 奖励内容 |
|---|---|
| Lv.8 | 卡牌奖励项×2（替代参数99999）；彩球 15分钟；炸弹 15分钟；开局火箭 15分钟 |
| Lv.9 | 卡牌奖励项×3（替代参数99999）；生命 60分钟；彩球×1；炸弹×1；开局火箭×1 |
| Lv.10 | 卡牌奖励项×4（替代参数99999）；金币×200；锤子×1；拳套×1；局内火箭×1；骰子×1 |
| Lv.11 | 卡牌奖励项×6（替代参数99999）；金币×500；彩球 30分钟；炸弹 30分钟；开局火箭 30分钟 |
| Lv.12 | 卡牌奖励项×9（替代参数99999）；金币×1000；锤子×1；拳套×1；局内火箭×1；骰子×1 |

卡牌项保留原始替代参数99999，尚不能据此写成固定星级卡包；最终奖励还可能按活动绑定和未拥有条件追加头像框。秋季截图中的“Min.1 New”及头像框不等于包内所有主题固定发放同样内容。TS 应换成自己的可用奖励与最终定稿数值。

## 5 棋盘、开局与覆盖

棋盘6列×8行、48格。配置行1为底行，底行第1／6列各为一级物品＋底层限制物，其余4格为空；其余7行共42格采用“预置棋子＋底层限制物11000＋全覆盖10000”。开局没有独立5×5教学盘。

|---|---|---|---|---|---|---|---|
| 1 | 10101 | 空 | 空 | 空 | 空 | 10101 | false |
| 2 | 10102 | 10102 | 10101 | 10101 | 10102 | 10102 | true |

基础表与_1仅第7行第1列预置主链10109→10107不同。本文不将两份表直接命名为难度AB组。

布局变体、两版BP、AP选表／开轮锁表及理论资源缺口复算，集中见 [[02-PROJECTS/产品分析/PiggyKingdom/活动/MergeJoy/数值分层与选表-2.7.3|数值分层与选表]]。基础／变体预置主链分别为1501／1309个Lv.1等值，差192；该口径包含覆盖底物，不是开场可花余额或实测完成成本。BP免费奖励相同，但两版仍有freeBoxType／paidBoxType表现字段差异。

全覆盖10000：不可拖动、阻挡合成、能受相邻合成挖除。合成成功后，只检查合成落点上下左右四邻，一次移除一层，不含对角、不按拖拽起点触发。

底层限制物11000：不能拖动，不接受上述挖除伤害，但不阻挡寻找可合成棋子。露出的棋子可接受外部同级棋子合成，完成后生成可操作的新物品并清除对应限制。两种状态构成“先揭开，再合成解锁”，无需火焰计数。

## 6 Joy 与 Fantasy 的链路和棋盘差异

| 内容 | Joy | Fantasy |
|---|---|---|
| 主链 | 12级主链 | 12级主链 |
| 额外生产链 | 无喂养生产链 | 5级饲料链、9级动物产物链 |
| 奖励链 | 金币链5级＋道具链5级 | 金币链5级＋道具链5级，金币链末级默认50金币 |
| 棋盘 | 6列×8行；misc.moveLines=0、checkLines=0 | 实拍7列×7行视窗，配置另有后续行；主链5～11级依次推进云目标，末3段配置移2／2／1行 |
| 阶段含义 | 同一主链持续成长，等级礼包不等于一张新地图 | 云目标推动开放和纵向移盘，不能直接解释为每段替换一条主链 |
| 首次发现奖励 | 进度条礼包与物品目标BP | 主链奖励、图鉴奖励，BP按工具消耗 |

两者的跨轮主题切换与一期内主链成长应分开看。当前没有依据把“主链满级后必切下一条主链”作为任一活动的通用规则。Fantasy详细产能、喂养、云目标及15档BP见 [[02-PROJECTS/产品分析/PiggyKingdom/活动/MergeFantasy/逻辑与配置-2.7.3|Fantasy详细规则]]。

## 7 到期、完成与最终退出

普通关闭、活动到期与领取最终大奖是三个状态，不能使用同一套“全部兑换”描述。

| 场景 | 包内实际处理 | 尚未覆盖的边界 |
|---|---|---|
| 活动期普通关闭 | 关闭面板并保留进度；与最终退出分流 | 未实机验证冷启动恢复 |
| 到期弹出 | 存在最后处理机会，或BP待领／未购买展示条件时，打开活动页收尾；否则打开结束页 | 未证实固定额外延长时长；返回棋盘不等于所有操作都继续开放 |
| 最后处理机会 | IsOpen且主链已到顶但终奖未领，或IsOpen且coins>0；shelvedItems和普通奖励物不参与此判定 | HasUnclaimedRewards不是任意未领奖励；已进入的棋盘有继续操作路径，不代表无限期重入 |
| 最终退出 | 协程先补有资格的BP普通奖励，剔除Joy投放资源，再执行ExitMatches与奖励反馈；付费轨必须已购买 | 过滤后清单为空则不显示BP奖励列表；结束页直达ExitMatches是另一分支；整段实机表现未验证 |
| 棋盘奖励补发 | 扫描可视棋盘顶层，排除主链，对自身有奖励的物品发放对应奖励 | 不自动升级低阶棋子，不补未达主链礼包；该扫描不遍历暂存物或被覆盖的底层棋子 |
| 剩余基础资源 | 仅已领最终大奖且coins>0时发送固定1个fist／拳头并清零coins | 品类6及数量1.0已按同构建IL／原生float算法核实；非按余额比例，实际到账待验证 |
| 暂存物 | 最终退出不补发、不折算、不能继续使用，新期不继承 | CloseRound未逐项删除暂存列表，不能把失去使用资格写成即时物理清空存档 |
| 图鉴补领 | Joy没有额外图鉴补领覆盖，基类默认无追加 | Fantasy的图鉴收尾不能套入Joy |

证据：MergeDataModelBase.IsLastChance／ExitMatches／CheckAndSendUnclaimedReward（0x060011d0／11d3／11d5），MergeminiActivity.PopUpEndPanel（0x06001f35），MergeGameViewBase.OnBtnClose／TryShowMergePassOnEnd及WaitCloseQuit协程；逐段位置见原始目录merge-joy-review-20261124/joy-rules-evidence.md。

TS采用一周周期是本项目决策。竞品默认排期、当前账号有效排期和到期收尾可操作窗口分别核对，不用截图剩余6d23h推算完整生命周期。定稿补证见 [[02-PROJECTS/产品分析/PiggyKingdom/活动/MergeJoy/完成到期与结算-2.7.3|完成、到期与结算专题]]。
