## 5. 可复现读取方式

ADB 使用绝对路径 `E:\MuMuPlayer\nx_main\adb.exe`，固定 `-s 127.0.0.1:16384`。先确认设备连接与包版本，再在已确认的包目录内操作。

```sql
-- App 库：只选游戏配置，不读取 Token 等键。
SELECT Key, hex(Value) FROM KeyValue
WHERE Key IN ('LavaQuestConfig','LavaQuestConfigVersion');

-- 账号库：只选活动字段，具体账号库名在设备上确认。
SELECT Id, hex(Value) FROM LavaQuestTableItem
WHERE Id IN ('ServerEventId','EnteredEventId','EnteredEventScenario',
             'ScenarioId','QualifiedUsers','EnteredEventWinnerCount',
             'ServerEventEndDate');
```

设备 SQLite 使用 `-readonly`。该版本不支持 `.mode json`，因此采用 hex(Value) 经主机 UTF-8 解码后生成 JSON。数据库 SELECT 与资源文件拉取都保持只读。

Unity 解析器：`D:\LibraryG\06-PRODUCT-ASSETS\_Tools\unity-analysis\Scripts\python.exe`，隔离环境安装 UnityPy 1.25.4，未改变系统 Python。脚本仅面向本次目录，不作为已验收的通用采集产品。
