# Royal Match 38911 活动清单与简述

> [!summary] 统计口径
> `EventsHelper` 在 38911 客户端中直接绑定 36 个活动或活动化模块，构成关卡进入、胜负和 Home Flow 回流的中央活动清单。客户端还存在每日奖励、周任务、赛季卡牌、Mission 系列和旧版兼容管理器，但它们不全部经过同一套中央回调，因此单独列在文末。

## 说明

- **已确认**：类名、管理器绑定、主要状态字段和关卡回调来自 Cpp2IL 静态代码。
- **简述**：优先按代码中的进度、排名、阶段、奖励、Offer、邀请等字段描述；尚未深入到配置的活动只给功能轮廓。
- **未确认**：38911 当前线上是否开启、具体档期、玩家分群、奖励数值和服务端覆盖。

## 一、长期进度、通行证与通用活动

| 活动/模块 | 类型 | 简要描述 |
|---|---|---|
| League | 长期进度/竞争 | 根据关卡进度进入 League，并处理排名、晋级或阶段切换；同时参与胜利返回 Home 的展示流程。 |
| Royal Pass | 通行证 | 跨多局累计进度并按阶段领取奖励的 Pass 系统，具有独立主题和活动入口。 |
| Weekly Pass | 周期通行证 | 周期较短的 Pass 变体；关卡进入与胜利会更新其进度。 |
| Madness | 收集进度 | 在关卡中收集指定 `ItemType` 或 `MatchType`，推进 `MadnessStep` 奖励阶段。 |
| Super Booster | 连续状态/强化 | 提供一段时间或连续挑战中的强化 Booster；失败会进入相应状态处理。 |
| Invite Friends | 社交拉新 | 好友邀请、邀请状态和奖励领取模块。 |

## 二、个人、团队与排行榜竞争

| 活动 | 类型 | 简要描述 |
|---|---|---|
| Kings Cup | 个人排名 | 玩家加入分组，累计分数并计算名次；活动结束后获取最终榜单和奖励。 |
| Team Battle | 团队对抗 | 记录个人分、团队分、分组和排名，围绕团队之间的分数竞争结算。 |
| Sky Race | 分组竞速 | 玩家或团队加入 Race 分组并推进比赛，包含可加入、比赛结束和无胜者等状态。 |
| Archery Arena | 竞技收集 | 关卡收集物可带倍率计入活动，存在最终榜单、胜负和领奖状态。 |
| Team Tournament | 团队排行榜 | 团队累计关卡活动分并参与排行榜结算，个人贡献会进入团队总成绩。 |
| Daily Lightning Rush | 每日竞赛 | 每日型计分活动，向服务端更新分数，并在结束时获取最终榜单和奖励。 |
| Propeller Rush | 收集竞赛 | 以关卡内螺旋桨相关收集量计分，包含排行榜、最终榜单与领奖流程。 |
| Robot Rivals | 三阶段对抗 | 收集弹药后攻击对手，分三阶段推进；匹配延迟后客户端可请求加入 Bot 对手，具体 Bot 数据由服务端返回。 |
| Clash of Champions | 对抗玩法 | 具有加入、专用 Gameplay、胜负、最终领奖等状态的冠军对抗活动。 |
| Royal World Cup | 淘汰赛/国家赛 | 可选择国家，按阶段比赛并处理晋级、淘汰、阶段榜单和活动最终榜单。 |

## 三、关卡连胜、阶段挑战与短周期促活

| 活动 | 类型 | 简要描述 |
|---|---|---|
| Pinata Party | 阶段奖励 | 以 Pinata 主题组织进度与奖励阶段，支持主题切换和活动入口状态。 |
| Space Mission | 连续挑战 | 包含加入、完成、失败、领奖和再次加入等状态，关卡失败会直接通知活动管理器。 |
| Balloon Rise | 连续推进 | 用气球数量表示活动进度，关卡结果和剩余收集物可影响推进或结束状态。 |
| Lava Quest | 连胜淘汰/竞争 | 玩家与 99 名历史数据模拟玩家组成 100 人局；24 小时内连续首过 7 关，失败结束本轮。胜者均分 10,000 金币，失败后当前公开规则为等待 30 分钟重试。 |
| Magic Cauldron | 收集阶段 | 收集 Elixir，填充 Shelf 并推进 Stage，完成阶段后发放奖励。 |
| Dragon Nest | 邀请/阶段活动 | 具有独立进度、配置、邀请和 UI 数据；围绕 Dragon Nest 主题推进活动阶段。 |
| Duke's Fortune | 机会型奖励 | 具有独立 Slot Machine Helper，围绕抽取/转盘式结果推进奖励流程。 |
| Duke's Treats | 阶段领取 | 按步骤领取奖励，轮次间可进入冷却，并存在使用金币跳过冷却的配置入口。 |

## 四、支线冒险与独立玩法

| 活动 | 类型 | 简要描述 |
|---|---|---|
| Hidden Temple | 探索活动 | 使用 Axe 资源探索独立 Board，按 Stage 推进并记录已完成阶段。 |
| Train Journey | 旅程活动 | 带独立进度、邀请、服务端事件状态和 UI 数据的旅程型活动。 |
| Ocean Odyssey | 支线关卡 | 带独立关卡下载和进度管理的海洋主题支线玩法，可从主流程切入专用关卡。 |
| Puzzle Break | 独立活动玩法 | 使用独立进度、配置、Helper 和远端 Bundle；具体棋盘规则待下一轮细化。 |
| Ancient Adventure | 分阶段连胜冒险 | 过关自动加入；单阶段版本需 7 连胜，三阶段版本依次需 5/7/10 连胜。失败将当前阶段 Step 归零，可立即重来；支持中途奖励、阶段奖励和可选 Heist 翻牌。 |
| Merge Smith | Merge 玩法 | 具有独立 Merge Game Model，通过关卡收集物驱动合成玩法，并配有活动 Offer。 |
| Short Expedition | 短期远征 | 较短周期的独立远征玩法，包含单独进度、Pass、每日 Offer 和结束 Offer。 |

## 五、团队协作、奖励与商业化覆盖

| 活动/模块 | 类型 | 简要描述 |
|---|---|---|
| Team Treasure | 团队协作 | 同时记录个人分和团队分，按 Team Segment 推进团队宝藏与贡献奖励。 |
| Ladder Offer | 阶梯 Offer | 按阶段逐级展示或领取内容的限时 Offer；具体免费/付费梯度待配置细化。 |
| Team Offer | 团队 Offer | 与团队状态关联的活动化礼包或奖励入口。 |
| Journey Offer | 旅程 Offer | 与旅程/活动进度联动的限时 Offer，胜利返回 Home 时可插入展示流程。 |
| Starfall Offer | 星星进度 Offer | 与星星或关卡进度相关的活动化 Offer；具体梯度和触发阈值待配置细化。 |

## 中央清单之外的活动相关系统

以下模块存在于 `UserContextId`，但不计入上面的 `EventsHelper` 36 项中央清单：

| 模块 | 归类 | 简要描述 |
|---|---|---|
| Seasonal Card Collection | 长期收集 | 赛季卡牌、卡包、套组完成和赛季奖励。 |
| Card Collection | 收集基础层 | 卡牌收集的通用数据与逻辑基础。 |
| Daily Rewards | 日常留存 | 每日登录或每日领取奖励。 |
| Weekly Mission | 周任务 | 周期任务、进度和奖励。 |
| Mission Pursuit / Mission Control | Mission 活动 | 两类任务活动管理器，具体任务结构待单独拆解。 |
| Weekly Leaderboard | 周榜 | 周期排行榜模块。 |
| Welcome Back Gift | 回流 | 面向回流用户的欢迎奖励。 |
| Lightning Rush / World Cup / Old Balloon Rise | 旧版或并存变体 | 客户端仍保留的同类旧入口或兼容管理器；是否线上使用待确认。 |
| King Nightmare / King Workshop | 独立主题功能 | 具备独立管理器的 King 主题功能，尚未确认是否按普通活动口径展示。 |
| Super Duke / Magic Duke / Cloche | 局内强化 | 与关卡强化、连胜或特殊 Booster 状态更接近，不宜直接算作排行榜活动。 |
| Extreme Levels / Three Color Levels | 关卡变体 | 属于特殊关卡规则，不计为活动。 |
| Offer / Segment Offer / Dynamic Offer / Coin Shop 等 | 商业化系统 | 提供通用、分群、动态和商店型 Offer，不全部属于有独立玩法周期的活动。 |

## 当前建议的下钻顺序

2026-10-26 用户已明确改为以清单逐项建立独立活动档案，首项为 Lava Quest。执行进度以 [[02-PROJECTS/产品分析/Royal Match/活动/_MOC|活动逐项拆解 MOC]] 为准；[[02-PROJECTS/产品分析/Royal Match/活动/Lava Quest/README|Lava Quest 独立档案]] 已补运行后配置、已保存分组和六个资源包解析。下列顺序保留为 10-21 历史建议，不代表当前执行顺序。

1. **Robot Rivals**：机器人相关最明确，可继续拆匹配、弹药、攻击、三阶段和奖励。
2. **Lava Quest / Space Mission / Balloon Rise**：适合对比失败惩罚和连续挑战结构。
3. **Ocean Odyssey / Ancient Adventure / Merge Smith**：代表三种不同的支线玩法框架。
4. **Kings Cup / Team Tournament / Royal World Cup**：可对比个人、团队和淘汰赛榜单。
