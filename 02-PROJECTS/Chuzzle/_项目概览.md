# Chuzzle 项目概览

## 定位

ChuzzleDemo 是 Unity / C# 项目，围绕“整行或整列循环移动”制造消除的关卡玩法构建。首个可玩闭环涵盖关卡进入、Line Shift、匹配与连锁、掉落补充、目标与步数、胜负、Continue，以及可选的 View、Robot / Replay / Reconnect 支持。

## 玩家与产品范围

- 玩家选择棋子，拖动其所在 Segment，并在松手后提交循环位移；无有效 Match 时回弹且不扣步。
- 有效位移进入 Match / Damage、Fall / Refill / Cascade、Booster Reaction、目标与胜负判定的闭环。
- 首期内容包括八种 Normal Element、Booster、Hint、Shuffle、Continue、关卡目标、有限步数、Record 与确定性 RNG。
- Player 可装配 View；Robot / Replay 可不装配 View，但应共享同一 Logic。

详细规则以仓库文档 `Docs/02-整体方案概述/00-产品范围与玩家规则.md` 为设计来源，尚未逐条与当前实现做一致性审计。
