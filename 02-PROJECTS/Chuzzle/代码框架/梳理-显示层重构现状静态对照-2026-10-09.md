# Chuzzle 显示层重构现状静态对照

## 当前代码已证实

| 边界 | 源码静态事实 |
|---|---|
| View 入口 | `ChuzzleViewController` 是 `IChuzzleViewController` 与 `IChuzzleGameWindowView` 的同一 partial 类型；构造中创建 HUD、Layout、Visuals、Preview 与 Motion 协作者 |
| Board 几何 | `BoardLayout` 持有棋盘几何、格子命中、裁剪与适配操作 |
| Board 元素 | `BoardVisuals` 持有元素映射、目标格、预览填充、伤害与裁剪投影 |
| 预览 | `BoardPreview` 持有 Segment、偏移、预览副本与回弹状态，依赖 Layout / Visuals |
| Unity 输入 | `BoardInput` 仅保存绑定期 Controller 并转交 EventSystem 回调；手势状态不在该 MonoBehaviour 中 |
| 游戏结果投影 | `ChuzzleApplication` 持有 Session、Logic、LevelLogic 与可选 View，按正式 `ActionResultBatch` 分派给 View；`ChuzzleGameplaySession` 实现玩家 / 窗口动作入口 |

> [!warning]
> 当前代码目录中的 `ChuzzleViewController*.cs` 与 `Board/*.cs` 可支持“职责拆分已存在”的静态结论；不能支持“所有方案已验收”“历史全绿仍然有效”或“Player 已通过”的结论。

## 当前可复查调用方向

```text
ChuzzleGame
→ ChuzzleApplication（结果投影、持有/释放 Session 与 Logic）
→ ChuzzleViewController（表现时间线和窗口合同）
├─ BoardLayout（几何）
├─ BoardVisuals（元素实例 / 投影）
├─ BoardPreview（预览 / 回弹）
├─ BoardInput（Unity 事件转发）
└─ ChuzzleHudPresenter（HUD）
```

逻辑状态推进和 Player 命令权威仍在 `ChuzzleGameplaySession` / Logic；View 只消费正式结果与投影，不应以动画完成阻塞玩法推进。这是当前源码和 D08 意图相符的静态结论。
