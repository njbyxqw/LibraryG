# Chuzzle 代码框架总览

## 目录地图

```text
Assets/Game/Chuzzle/
├─ Config/                 关卡、元素、Booster 生成与程序化关卡配置
├─ Scripts/
│  ├─ DomainEvent/         领域事件基础
│  ├─ Entry/               宿主进入点
│  ├─ GameCore/
│  │  ├─ Application/      输入与表现用例层
│  │  ├─ Game/             每局装配与生命周期
│  │  ├─ Logic/            接口、玩法推进与关卡状态
│  │  └─ View/             表现与 UI 协作
│  ├─ GameRecord/          Record / Replay / Snapshot 相关能力
│  ├─ UI/                  游戏、退出、复活、胜利窗口
│  └─ Util/                共享工具
├─ Res/                    棋盘、障碍、毛绒、UI 等资源
├─ Editor/                 编辑器、试玩、Bot、编辑器关卡数据
├─ Tests/EditMode/         EditMode 测试程序集
├─ Tests/PlayMode/         PlayMode 测试程序集
└─ XAsset/                 资源投递相关内容
```

## 程序集职责（静态清单）

| 程序集 | 目录 | 职责线索 |
|---|---|---|
| `Chuzzle.Config` | `Config/` | 玩法与关卡配置模型 |
| `Chuzzle.DomainEvent` | `Scripts/DomainEvent/` | 领域事件基础 |
| `Chuzzle.Logic.Interface` | `Scripts/GameCore/Logic/Interface/` | Logic 对外合同 |
| `Chuzzle.Logic.GameLogic` | `Scripts/GameCore/Logic/GameLogic/` | 消除、掉落、连锁等玩法推进 |
| `Chuzzle.Logic.LevelLogic` | `Scripts/GameCore/Logic/LevelLogic/` | 关卡/终局状态 |
| `Chuzzle.Game` | `Scripts/GameCore/Game/` | 单局装配、生命周期与更新编排 |
| `Chuzzle.Application` | `Scripts/GameCore/Application/` | 输入到玩法与结果消费的用例层 |
| `Chuzzle.View` | `Scripts/GameCore/View/` | 棋盘/UI 表现协作 |
| `Chuzzle.GameRecord` | `Scripts/GameRecord/` | 记录、回放、恢复相关实现 |
| `Chuzzle.Editor` | `Editor/` | 关卡编辑、试玩、Bot、校验工具 |
| `Chuzzle.Tests.EditMode` / `Chuzzle.Tests.PlayMode` | `Tests/` | 自动化测试边界 |

## 核心设计调用链（文档合同）

```text
宿主 / ChuzzleModule
→ ChuzzleGame（单局装配、Update、释放）
→ ChuzzleGameLogic（唯一玩法状态 writer）
→ ChuzzleLevelLogic（关卡与终局状态）
→ 可选 ChuzzleApplication / ChuzzleViewController（输入与表现）
```
