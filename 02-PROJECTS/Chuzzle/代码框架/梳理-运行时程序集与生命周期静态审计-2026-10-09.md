# Chuzzle 运行时程序集与生命周期静态审计

## 结论摘要

当前源文件与程序集定义显示：`Chuzzle.Game` 是运行时装配层，直接依赖 Config、Logic、Record、Application、View 与 DomainEvent；`ChuzzleModule` 管理唯一的 `CurrentGame`，并通过 Scene state 进入/退出。运行时主循环从 Module 转发到 Game，再由 Game 推进 Record、Replay、Timer、GameLogic 与结果投递。

本次未运行 Unity 或编译。生成的 `Chuzzle.Game.csproj` 中的源文件路径与当前实际资源路径不一致，必须先在 Unity 中刷新工程文件，再把该生成项目当作编译归属依据。

## 静态生命周期链

```text
ChuzzleModule.Init
  → 加载 ElementConfig、取得 Scene/UI/Implement 服务
  → 注册 ChuzzleSceneState
  → RegisterImplement 注册 Candidate（可能另注册 Reconnect Candidate）

OpenGotoGamePanel
  → 加载 Booster 规则与 LevelConfig
  → TransitionState(CandidateSceneStateId)
  → ChuzzleSceneState.OnEnter
  → ChuzzleModule.EnterLevel
  → CreateGame / CreateReplayGame / CreateReconnectGame
  → ChuzzleGame.Initialize

ChuzzleModule.OnUpdate
  → CurrentGame.Update(deltaTime)
  → Record Advance / Replay root（如有）
  → 暂停门禁
  → Timer.Tick → ChuzzleGameLogic.Update
  → CompleteRecordedBatch → DeliverResults

Scene OnExit 或 Module Dispose
  → CurrentGame 置空
  → ChuzzleGame.Dispose
  → 取消生命周期、注销事件、释放 Application 或 Logic、关闭窗口
```

## 待核实风险：生成项目路径不同步

当前真实源码包含：

- `Assets/Game/Chuzzle/Scripts/Entry/ChuzzleModule.cs`
- `Assets/Game/Chuzzle/Scripts/Entry/ChuzzleSceneState.cs`

但当前生成的 `Chuzzle.Game.csproj` 仍列出不存在的 `Assets/Game/Chuzzle/Scripts/Game/ChuzzleModule.cs` 与 `ChuzzleSceneState.cs`，同时也列出多个 `Scripts/Game/` 文件。该 `.csproj` 自己标注为 generated file，因此本次仅记录“生成文件与资源路径不一致”。

- **不能推出**：Unity 当前一定无法编译。
