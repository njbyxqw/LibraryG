# Chuzzle 记录回放恢复与测试覆盖静态地图

## 记录 / 回放 / 恢复链

```text
Live Game
→ ChuzzleRecordController.CreateLive
→ {persistentDataPath}/Chuzzle/Records/{RecordId}.record
→ 每个稳定 Root 完成后捕获状态
→ {persistentDataPath}/Chuzzle/ChuzzleSnapshot.snapshot

Replay
→ 读 .record → 校验 Level / Element / Booster Content Hash 与版本
→ 按记录时间消费 Root → 比对 checkpoint

Reconnect
→ 读 Snapshot identity → 校验 Header / Record / Hash
→ 读 snapshot checkpoint；损坏且允许时从活动 Record 回退
→ 回放 Record 尾部 → 继续同一 RecordSequence
```

| 能力 | 代码入口 | 静态门禁 / 行为 |
|---|---|---|
| Live | `ChuzzleModule.CreateGame` → `ChuzzleRecordController.CreateLive` | 创建新 `.record`；写入 Header 后才追加 Root / Checkpoint |
| Replay | `TryCreateReplay` | 必须匹配关卡 ID、Game / Build 版本、Level / Element / Booster Hash；不匹配即拒绝 |
| Reconnect | `TryCreateReconnect` | Snapshot 身份、活动 Record Header、checkpoint cursor、LogicSequence、Outcome 与 StateHash 必须一致；允许的 Snapshot body 失败可退回 Record |
| Snapshot | `ChuzzleSnapshotStore` | 固定文件名 `ChuzzleSnapshot.snapshot`，上限 16 MiB；稳定 Root 完成时尝试写入 |
| 释放 | `ChuzzleModule.Dispose` / `ChuzzleGame.Dispose` | Game 与 Controller 分别释放；是否所有异常路径均无残留需要运行验证 |

> [!warning]
> 上述 `persistentDataPath` 目录和二进制格式只来自静态代码。真实设备的读写权限、升级兼容、文件损坏与断电恢复结果尚未执行验证。
