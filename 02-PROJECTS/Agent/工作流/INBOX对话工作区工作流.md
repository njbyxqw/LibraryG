# INBOX 对话工作区工作流

> 当前定位：仅在整理 `00-INBOX/`、处理临时对话产物或恢复旧 inbox-organizer 流程时读取；不作为日常 TS/MT 代码逻辑读取任务的必读规范。

## 定位

`00-INBOX/` 是每次对话的**工作区**——纯粹的中间产物容器，不做任何分类判断。
该话题是否与已有对话重复、产物最终去哪，都在"整理 INBOX"阶段统一处理。

## 与 inbox-organizer Skill 的关系

本规范定义**结构**，`inbox-organizer` Skill 执行**整理**。

- **INBOX 建文件夹时**：直接 `mkdir + 日期-主题`，不管同类话题
- **整理 INBOX 时**（你一句话触发）：Skill 扫描所有对话文件夹 → 按分类规则建议去向 → 检测同类/冲突 → 等你确认后执行移动/删除

## 对话文件夹命名规范

```
格式：YYYY-MM-DD-简短主题
示例：2026-07-01-知识库分类标准
     2026-06-28-关卡花色分析
```

## 完整工作流

```
┌─ 对话开始 ──────────────────────────────────────────────────┐
│                                                             │
│  INBOX/<日期-主题>/   ← 建对话文件夹                          │
│       │                                                     │
│       ├── 中间产物.md        ← 对话产生的草稿、报告、分析     │
│       ├── 比对结果.md                                         │
│       └── ...                                                 │
│       │                                                     │
│       ▼  对话中形成规范/结论                                  │
│       │                                                     │
│       ├── 规范类 → 移动到 03-KNOWLEDGE/工作流/                │
│       ├── 项目类 → 移动到 02-PROJECTS/<项目名>/               │
│       ├── 知识类 → 移动到 03-KNOWLEDGE/<主题>/                │
│       └── 日志类 → 同步到 01-DAILY/YYYY-MM-DD.md              │
│                                                             │
│       ▼  对话结束                                            │
│                                                             │
│      对话文件夹处理：                                         │
│      ├── 内容已全部移动（空文件夹） → 删除                     │
│      └── 还有残留中间产物     → 归档到 05-ARCHIVE/             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 产物分类判断

| 产物类型 | 目标目录 | 示例 |
|---------|---------|------|
| 规范/流程文档 | `03-KNOWLEDGE/工作流/` | 分类标准、同步流程 |
| 技术知识 | `03-KNOWLEDGE/<主题>/` | Unity 技巧、编辑器原理 |
| 项目文档/报告 | `02-PROJECTS/<项目名>/` | TileMatch 功能分析 |
| 日志 | `01-DAILY/YYYY-MM-DD.md` | 每日工作记录 |
| 纯中间产物 | 对话结束后删除或归档 | 临时比对表、草稿 |

## 与 DAILY 的配合

- **DAILY 记录"做了什么"**：在每日笔记中记录本次对话的关键产出和决策
- **INBOX 存放"产物本身"**：对话中产生的具体文件
- **同步时机**：对话中形成结论时，立即移动产物到目标目录并更新 DAILY 日志

## 注意事项

- 产物同步默认使用**移动**（非复制），避免冗余副本
- 规范文档产出后立刻移动，不留在 INBOX
- 附件统一放 `00-INBOX/attachments/`
- 如果对话文件夹在结束后非空，说明有未处理的产物
