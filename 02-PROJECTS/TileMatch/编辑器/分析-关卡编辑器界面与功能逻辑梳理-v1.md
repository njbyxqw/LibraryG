# 关卡编辑器界面与功能逻辑梳理

> **分析范围**：`TileV2/Editor/LevelEditor/` 目录完整结构（153 个 .cs 文件），核心架构代码，命令系统，参数编辑策略系统，数据管理层，验证系统。

---

## 一、编辑器概述

TileMatch 关卡编辑器是一个 **Unity EditorWindow** 扩展，用于创建、编辑、验证关卡配置（JSON 文件）。

**核心功能**：
- 关卡列表管理（虚拟滚动）
- 棋盘视图（BoardView，11 个 partial class）
- 参数编辑（9 个 IParameterStrategy 实现）
- 命令系统（Undo/Redo，20 种 CommandType）
- 图层管理
- 验证系统（10 个 Validator + PostValidate）

---

## 二、架构总览

### MVC + Command + Strategy + Observer

| 层级 | 文件 | 职责 |
|------|------|---------|
| **Model** | `LevelDataManager` / `LevelListDataManager` | 数据管理层（Singleton + 事件驱动） |
| **View** | `LevelEditorViewManager`（接口） + `BoardView`（11 文件拆分） | 视图层 |
| **Controller** | `LevelEditorController` | 核心控制器（键盘快捷键、菜单项） |
| **Command** | `ICommand` / `CommandManager` | Undo/Redo 双向链表 |
| **Strategy** | `IParameterStrategy`（9 实现） | 参数编辑策略 |
| **Observer** | `DomainEventBus`（双通道） | 消息/事件系统 |

### 关键设计模式

1. **Partial Class 拆分**：`BoardView` 拆成 11 个文件（主视图/Tile/Effect/Pile/Event/Grid/Layer/Preview/BatchSession）
2. **责任链模式**：参数编辑策略匹配（`IParameterStrategy` 责任链）
3. **命令模式**：Undo/Redo 双向链表，20 种命令类型
4. **观察者模式**：双通道 `DomainEventBus` + `MessageDispatch`

## 四、核心视图详细分析

### 4.1 BoardView（11 文件拆分）

**设计目的**：`BoardView` 太大（~3000 行），拆成 11 个 partial class 便于维护。

| 文件 | 职责 |
|------|---------|
| `BoardView.cs` | 主视图（初始化、绘制、事件路由） |
| `BoardView_Tile.cs` | Tile 绘制/点击检测 |
| `BoardView_Effect.cs` | Effect 绘制/点击检测 |
| `BoardView_Pile.cs` | Pile 绘制/点击检测 |
| `BoardView_Event.cs` | Event 绘制/点击检测 |
| `BoardView_Grid.cs` | Grid 绘制/点击检测 |
| `BoardView_Layer.cs` | Layer 管理 |
| `BoardView_Preview.cs` | 预览模式 |
| `BoardView_BatchSession.cs` | 批量操作会话 |
| `BoardView_Selection.cs` | 选择管理 |
| `BoardView_UndoRedo.cs` | Undo/Redo 视图更新 |

### 4.2 LayerView（图层管理）

- **功能**：显示/隐藏图层，调整图层顺序
- **实现**：`LayerView.cs` + `LayerViewModel.cs`
- **事件**：`LayerChangedEvent` → `DomainEventBus`

### 4.3 LevelListView（虚拟滚动）

- **问题**：关卡列表可能包含 5000+ 个文件，一次性加载会卡死
- **解决方案**：虚拟滚动（只渲染可见区域的关卡）
- **实现**：`LevelListView.cs` + `VirtualizedListControl`

## 五、命令系统

### 5.1 Undo/Redo 双向链表

```csharp
public class CommandManager
{
    private LinkedList<ICommand> _undoStack;
    private LinkedList<ICommand> _redoStack;
    
    public void Execute(ICommand command)
    {
        command.Execute();
        _undoStack.AddLast(command);
        _redoStack.Clear();  // 执行新命令后，Redo 栈清空
    }
    
    public void Undo()
    {
        var command = _undoStack.Last();
        command.Undo();
        _undoStack.RemoveLast();
        _redoStack.AddLast(command);
    }
    
    public void Redo()
    {
        var command = _redoStack.Last();
        command.Execute();
        _redoStack.RemoveLast();
        _undoStack.AddLast(command);
    }
}
```

## 十一、关键工作流

### 11.1 创建关卡

1. `LevelListView` → "New Level" 按钮
2. `LevelFileMigrationWindow` → 创建 JSON 文件
3. `LevelDataManager.SelectLevel()` → 触发 `OnLevelSelected` 事件
4. `BoardView` → 刷新视图

### 11.2 编辑关卡

1. `BoardView` → 点击 Tile/Effect
2. `LevelParameterView` → 显示参数面板
3. 修改参数 → `ModifyDataCommand.Execute()`
4. `CommandManager` → 记录到 Undo 栈
5. `BoardView` → 刷新视图

### 11.3 SelectLevel

1. `LevelListView` → 选中关卡
2. `LevelDataManager.SelectLevel()` → 触发 `OnLevelSelected` 事件
3. `BoardView` → 刷新视图
4. `TileSelectionView` → 刷新花色（如果加载了花色加载扩展）

### 11.4 Undo/Redo

1. `LevelEditorController` → 捕获 `Ctrl+Z` / `Ctrl+Y`
2. `CommandManager.Undo()` / `Redo()`
3. `BoardView_UndoRedo.cs` → 刷新视图

## 十三、总结

### 架构特征

1. **MVC 清晰分离**：Model（LevelDataManager）/ View（BoardView）/ Controller（LevelEditorController）
2. **命令模式**：Undo/Redo 双向链表，20 种命令类型
3. **策略模式**：参数编辑 9 策略，责任链匹配
4. **观察者模式**：双通道 DomainEventBus
5. **Partial Class 拆分**：BoardView 拆成 11 个文件

### 编辑器 vs 运行时对比

| 维度 | 编辑器 | 运行时 |
|------|---------|---------|
| 目的 | 创建/编辑关卡 | 玩游戏 |
| 数据 | LevelConfig JSON | LevelConfig 运行时对象 |
| 交互 | 鼠标点击 + 键盘快捷键 | 触摸/鼠标 |
| 性能 | 可以慢（编辑器工具） | 必须快（游戏帧率） |
