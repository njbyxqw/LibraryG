# 牌局生成深度显示工具

> 调试工具，用于在 Unity Scene 视图中可视化关卡初始生成时每张牌的池归属（Tail/Shuffle/Trap）、深度排名和花色类型。配合 Console 聚合统计，验证"深度前 25% 不打乱"规则是否正确生效。

---

## 动机

`AssignTileTypeByDepthStrategy` 的"深度前 25% 普通牌不打乱"规则曾因 **slot 索引切分 bug** 和 **8a42d60c9f 提交回归**而失效。肉眼无法判断花色分布是否符合预期，需要一个可视化工具直接看。

## 一、Scene 视图色块覆盖

### 色标规则

| 色块 | 含义 | 标注内容 |
|------|------|---------|
| 🔵 蓝 | Tail 不打乱池 | 深度排名数字 + 花色短名(例:C3T1→"3-1") |
| 🟣 紫 | Trap 藏牌 | "TRAP" |
| 🟠 橙 | 序列子牌 | "SEQ" |
| ⬜ 灰 | 非随机固定牌 | 花色短名 |
| (无) | Shuffle 打乱池 | 不绘制，视觉清爽 |

### 使用方式

1. Unity 中 Play 进入关卡
2. 关卡加载完瞬间 Console 自动打印统计表
3. Scene 视图自动显示色块覆盖
4. 建议暂停查看，防止消除干扰初始状态

### 技术细节

- `Handles.zTest = LessEqual` + 色块 Z 偏移 0.3f，被上层牌遮挡的牌色块也会隐藏
- 通过 `TileData.SequenceId >= 0` 判断序列子牌，无需 Position 匹配
- 普通牌按 `Position (Vector3Int)` 做 key 查字典
- 全部 `#if UNITY_EDITOR` 包裹，不出现在正式包

## 三、实现原理

### 数据流

```
InvokeStrategy 执行
  → typeIndex 生成 + pool 切分完成
  → PopulateDebugMap() 写入静态字典 DebugSlotMap
     ├─ 普通牌 shallowSlots → Tail, Pool=Shuffle
     ├─ 普通牌 deepSlots → Shuffle Pool
     ├─ 序列牌 → 不写字典(Gizmos 用 SequenceId 判断)
     └─ Trap slots → Trap Pool
  → DumpDebugSummary() 输出 Console 统计

Gizmos (TilePoolDebugGizmo.cs)
  → SceneView.duringSceneGui 回调
  → FindObjectsOfType<TileView>() 遍历所有牌
  → 查 DebugSlotMap 或判断 SequenceId
  → Handles.DrawSolidRectangleWithOutline 画色块
```

### 数据结构

```csharp
#if UNITY_EDITOR
public enum SlotPoolType { Shuffle, Tail, Trap, NotRandom }

public struct DebugSlotInfo
{
    public PoolType poolType;
    public int depthRank;    // 1=最浅
    public int tileTypeValue; // 花色枚举
    public string tileTypeShortName; // "C3T1"→"3-1"
}

public static Dictionary<Vector3Int, DebugSlotInfo> DebugSlotMap;
#endif
```

## 四、踩坑记录

| 坑 | 现象 | 修复 |
|----|------|------|
| `TileEntry.tileIndex` 不存在 | 编译错误 CS1061 | `TileEntry` 只有 `Position`/`Size`，改直接取 `.Position`（3 处） |
| 命名空间冲突 | 90 条报错 `Debug.LogError` 解析失败 | 目录 `Script/Debug/` → `Script/TileDebug/`，命名空间同步 |
| FB SDK 手机 API | Windows Editor 报 `Mobile interface on non mobile platform` | `FB.Mobile.FetchDeferredAppLinkData()` 加 `#if UNITY_IOS \|\| UNITY_ANDROID` |
| `tv.Position` 不存在 | Gizmos 不显示色块 | `TileView` 无 `Position`，改 `tv.TileData.Position` |
| zTest 设反 | 暂停无颜色 / 被模型遮挡 | zTest 默认 `Always`（始终可见）已恢复 |
| Shuffle 池红色太杂 | 打乱池占大多数牌，红色覆盖混乱 | 取消 Shuffle 池绘制，保留蓝/紫/橙/灰 |
| 色块与牌层级不对 | Trap 紫块穿透上层牌 | zOffset 0.03f→0.3f + `zTest=LessEqual` |
| LINQ 未引用 | `OrderBy` 编译错误 | 加 `using System.Linq;` |
