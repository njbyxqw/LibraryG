# 编辑器快捷键系统

> **背景**：关卡编辑器需要快速选中障碍牌/特效的编辑工具。数字键 1~3 已由 Controller 原生处理（TileChildTile/TileChildPile），4~7 空闲可动态绑定。

---

## 一、ShortcutBindingManager 设计（原版）

### 文件位置

`Editor/LevelEditor/Script/Core/ShortcutBindingManager.cs`（311 行）

### 功能

- 数字键 **4~7** 动态绑定当前关卡的障碍牌/特效，一键选中编辑工具
- 三步映射算法：
  1. 扫描队列（Tiles 去重 → Effects 去重）
  2. 检查保留/清空
  3. 填补空位

### 依赖

- `LevelDataManager` — 获取当前关卡配置
- `TileType`, `EffectType` — 枚举类型
- `OptionState` — 编辑工具状态

## 二、本地扩展改造方案

### 改造原因

- 源码 `ShortcutBindingManager.cs` 已设计完成但未集成到 client 目录
- 需要改造为本地扩展，不修改源码

### 评估结论

- 所有依赖均通过现有 asmdef 引用可访问，**零新增依赖**
- 3 个关键改造：
  1. 命名空间 → `LocalExtensions`
  2. Singleton → **静态类 + `EditorApplication.update` 按键轮询**
  3. 关卡切换检测用**引用对比**

### 改造实施

**文件**：`client/Assets/Editor/LocalExtensions/LevelEditor_ShortcutBindingPatch.cs`（约 280 行）

#### 核心改造点

```csharp
using UnityEditor;
using UnityEngine;

[InitializeOnLoad]
public static class LevelEditor_ShortcutBindingPatch
{
    static LevelEditor_ShortcutBindingPatch()
    {
        EditorApplication.delayCall += Init;
    }

    private static void Init()
    {
        if (EditorApplication.isPlaying) return;
        EditorApplication.update += OnUpdate;
    }

    private static LevelConfig _oldConfig;

    private static void OnUpdate()
    {
        // 1. 关卡切换检测：引用对比
        var newConfig = LevelDataManager.Instance?.CurrentLevelConfig;
        if (newConfig != _oldConfig && _oldConfig != null)
        {
            RefreshFromBoard();
        }
        _oldConfig = newConfig;

        // 2. 输入框聚焦安全检测
        if (EventSystem.current?.currentSelectedGameObject?.GetComponent<InputField>() != null)
            return;

        // 3. 按键检测（4~7）
        if (Event.current != null && Event.current.type == EventType.KeyDown)
        {
            // ... 映射算法 ...
        }
    }
}
```

#### 保留原三步映射算法

- 扫描队列 → 检查保留/清空 → 填补空位
- 移除 TileChildTile/TileChildPile 类型（1~3 键由 Controller 原生处理）

#### 双注册防护

`_isRegistered` 标记防止 domain reload 重复注册

## 三、调试增强

添加完整诊断日志链，覆盖从初始化到按键触发的全链路：

| 日志节点 | 内容 |
|---------|------|
| 静态构造函数 | 确认 `EditorApplication.update` 已注册 |
| `LevelDataManager.Instance` 就绪检测 | 含 null 告警 |
| `CurrentLevelConfig` 内容输出 | LevelName / Tiles.Count / Effects.Count |
| 关卡切换 | RefreshFromBoard 触发节点 |
| 每 600 帧（≈10s） | 输出绑定状态快照（4 个槽位内容 + 关卡信息） |
| 输入框聚焦 | 日志提示快捷键禁用 |
| 按键检测 | 输出按键、槽位索引、绑定内容 |
| RefreshFromBoard 完成 | 输出队列长度 + 填充后非空槽位数 |
