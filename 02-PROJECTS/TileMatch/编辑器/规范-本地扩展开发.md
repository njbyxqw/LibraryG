## 二、asmdef 引用规则

Unity 的 asmdef **不传递依赖**，需显式声明每个用到的程序集。

### 当前引用清单

| 程序集 | 用途 |
|--------|------|
| `TileMatch.Editor` | 编辑器核心 API |
| `TileMatch.Config` | 配置数据结构（LevelConfig 等） |
| `BettaSDK` | Betta 框架 |
| `TileShared.Logic.DomainEvent` | DomainEventBus |

### 添加新引用检查清单

- [ ] 新程序集是否在 Unity 编译日志中报 `CS0234`（类型或命名空间不存在）？
- [ ] 是否在 `TileMatch.Editor.asmdef` 的 `references` 中声明？
- [ ] 是否需要同时引用 `TileMatch.Config` 和 `TileShared.Logic.DomainEvent`？

## 三、DomainEventBus 正确用法

### ❌ 错误用法（已修复）

```csharp

```

### ✅ 正确用法

```csharp
using Game.TileShared.Scripts.GameCore.DomainEvent;

// 静态调用
DomainEventBus.RegisterForEnumKey<YourHandler>(EventEnum.SelectLevel);
```

### 接口要求

- 必须使用 `IEnumKeyEventHandler<T>` 接口（不是裸 delegate）
- 用**嵌套类**桥接（示例见第四节）

## 四、反射安全模式

本地扩展需要访问私有字段/方法时，使用反射。

### 安全模板

```csharp
using System.Reflection;

public static class ReflectionHelper
{
    private static readonly BindingFlags PrivateInstance = 
        BindingFlags.NonPublic | BindingFlags.Instance;

    public static T GetPrivateField<T>(object obj, string name)
    {
        var fi = obj.GetType().GetField(name, PrivateInstance);
        return (T)fi?.GetValue(obj);
    }

    public static void SetPrivateField(object obj, string name, object value)
    {
        var fi = obj.GetType().GetField(name, PrivateInstance);
        fi?.SetValue(obj, value);
    }

    public static void CallPrivateMethod(object obj, string name, params object[] args)
    {
        var mi = obj.GetType().GetMethod(name, PrivateInstance);
        mi?.Invoke(obj, args);
    }
}
```

### 使用注意事项

1. **字段名变更风险**：Unity 重构私有字段名会导致反射失败，需单元测试覆盖
2. **性能**：反射调用比直接调用慢 ~100x，编辑器工具可以接受，运行时禁止
3. **空值保护**：`fi?.GetValue()` 和 `mi?.Invoke()` 必须加 null 条件运算符

## 五、时序处理

### 编辑器主循环注册

```csharp
using UnityEditor;

[InitializeOnLoad]
public static class YourExtension
{
    static YourExtension()
    {
        EditorApplication.delayCall += Init;
    }

    private static void Init()
    {
        if (EditorApplication.isPlaying) return;
        EditorApplication.update += OnUpdate;
    }

    private static void OnUpdate()
    {
        // 编辑器主循环逻辑
    }
}
```

### 关卡切换检测

```csharp
private static LevelConfig _oldConfig;

private static void OnUpdate()
{
    var newConfig = LevelDataManager.Instance?.CurrentLevelConfig;
    if (newConfig != _oldConfig && _oldConfig != null)
    {
        // 关卡切换，执行刷新
        Refresh();
    }
    _oldConfig = newConfig;
}
```

**关键**：用**引用对比** (`!=`) 检测关卡切换，不用 `LevelName` 字符串对比。
