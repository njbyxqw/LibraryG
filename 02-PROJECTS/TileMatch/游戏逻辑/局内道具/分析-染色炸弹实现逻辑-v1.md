# 染色炸弹实现逻辑

> 来源：`/Users/dean/Downloads/meatloaf_client/client` 分支 `tile/tile_dyeingbomb` 的静态代码与资源引用核对。本文记录当前实现；Unity 编辑器、设备和热更新资源运行时尚未验证。

## 运行时主链路

```text
Energy.json 的 LevelCollect(CollectKey=DyeingBomb)
  → DyeingBombSystem.AddEnergy()
  → 达到 DyeingBombConfig.MaxEnergy 后 TriggerDyeing()
  → CustomTargetFilterType.DyeingBomb 选取目标
  → TileService.ModifyTile(target, TileType.DyedSuit=1002)
  → ActionType.DyeingBomb / DyeingBombActionData
  → DyeingBombViewAction
  → TileView.SetIconSpriteByTileType(1002)
  → Res/Game/GameCore/Texture/Tiles/block_1002.png
```

### 染色触发与逻辑

- **能量牌定义**：`Assets/Game/TileV2/Config/TileConfig/Energy.json`，TileType 为 `5250`；点击收集时执行 `LevelCollect`，key 为 `DyeingBomb`，数量为 1。
- **触发门槛与选牌**：`Scripts/GameCore/Logic/GameLogic/Module/DyeingBomb/DyeingBombSystem.cs`。累计能量达到 `DyeingBombConfig.MaxEnergy` 后触发；目标经 `CustomTargetFilterType.DyeingBomb` 从高亮、可见、不可见、Bar 与 OverBar 池中选取。
- **状态修改**：每个目标直接改为 `TileType.DyedSuit (1002)`；Bar 内牌延迟通知 `BarChanged`，其余牌立即通知。没有独立的 DyedSuit Prefab 创建流程。
- **行为收口**：系统以 `ActionType.DyeingBomb` 分发 `DyeingBombActionData`，完成信号由 `OnDyeingComplete()` 解除处理锁并继续检查剩余能量。

## 表现链路

- **ViewAction**：`Scripts/GameCore/View/GameView/Views/ViewActions/DyeingBomb/DyeingBombViewAction.cs`。
- **目标牌换图**：在变色时间点调用 `TileView.SetIconSpriteByTileType(target.TileType)`；该方法按动态路径加载 `Res/Game/GameCore/Texture/Tiles/block_<TileType>.png`。
- **实际目标资源**：`Assets/Game/TileV2/Res/Game/GameCore/Texture/Tiles/block_1002.png`。当前内容与 `block_305.png` 一致，导入设置已对齐 `block_305`（512×512、PPU 450、Android/iOS Max Size 128、Format 48）。
- **提层/高亮边界**：当前 `DyeingBombViewAction` 不再对目标牌执行排序提层或高亮；只换 Icon 并播放爆炸粒子。该结论仅针对当前分支静态代码。

## 能量牌资源与暗态表现

### 能量牌资源链

```text
TileType.Energy=5250
  → tileblockercfg.bytes / tileblockercfg.json~ 的 id=5250
  → Prefab/TileView/Energy/Prefab/TileEnergy.prefab
  → Energy/Texture/block_9999.png
```

- `tileblockercfg.bytes` 是运行时 Protobuf；`tileblockercfg.json~` 是可读备份，二者当前将 `5250` 映射至 `TileEnergy.prefab`。
- `TileEnergy.prefab`、`DyeingBombCollectView.prefab` 与 `EnergyCollectMoveParticle.prefab` 都引用 `Energy/Texture/block_9999.png`（能量喷罐）。不要再将它们指向目标花色 `block_1002.png`，否则能量牌和染色目标会再次共用素材。
- `block_9999.png` 是 512×512、透明背景；其 `.meta` 以 `block_305.png.meta` 为基准，保持 Sprite Single、PPU 450、中心 Pivot、MipMap Off、Bilinear、Clamp、iOS/Android Max Size 128、Format 48。

### Pile 不可见态牌底

- `EnergyTileView` 在 `Data.InPile && EntityVisibility.NotVisible` 时关闭专用背景并显示 `plainBackground`。
- `plainBackground` 是 `TileEnergy.prefab` 的 `PileBackground`，当前引用 `Texture/Tiles/block_bg2.png`，因此与普通暗牌使用的全局 `BlockBgConfig=block_bg2` 一致。
- 此处不能用喷罐 Sprite 或目标花色 Sprite；它是不可见状态的牌底，尺寸为 118×132、PPU 100。

## 资源替换规则

| 诉求 | 正确替换入口 | 不应改动 |
|---|---|---|
| 染色后的目标花色 | `Texture/Tiles/block_1002.png` | `TileEnergy.prefab` 的能量 Sprite |
| 局内能量牌、收集展示、飞行粒子 | `Energy/Texture/block_9999.png` 与三处 Prefab GUID | `Texture/Tiles/block_1002.png` |
| Pile 暗态底图 | `TileEnergy.prefab` 的 `PileBackground` | 喷罐与目标花色资源 |
