# 染色炸弹能量牌收集表现试做与回退

> [!failure] 结论
> 本轮能量牌收集表现试做未达到预期，用户于 2026-10-12 确认“效果不好”，相关实现全部回退。本记录仅保留方案、实现边界和失败原因，不作为当前代码实现说明。

## 目标

能量牌点击收集后，将牌底与花色分层表现：牌底先轻微放大，再旋转缩小；牌底接近花色大小时，花色沿既有收集曲线飞向目标；牌底消失前增加颜料液滴迸溅。后续尝试将方形牌底先扭曲为螺旋轮廓，再旋转缩小。

## 试做内容

- 为 `TileType.Energy + ActionType.LevelCollect` 增加专用 ViewAction，使能量牌先播放退出动画，再调用既有收集飞行。
- 牌底起手放大由 `1.1` 调整为 `1.2`，随后缩小消失。
- 复用已有汁水喷溅粒子，并在运行时改为粉、黄、青、紫四色颜料液滴。
- 增加 `EnergyCollectVortex.shader` 和材质：前约 `0.14s` 收四角并形成双臂螺旋，后约 `0.22s` 旋转 `360°` 并向中心缩小。
- 为收集 UI 飞行补充起始 Sprite 世界尺寸，避免飞行起始比例跳变。

## 验证与问题

- Unity 完成脚本和 Shader 编译，Console 当时为 `0 error`；`git diff --check` 通过。
- 当前测试关卡的能量牌被冰层覆盖，点击先被冰层吸收，未完成能量牌收集链路的端到端肉眼验收。
- 实际观感仍不自然：方形牌底旋转感过强；后续螺旋 Shader 方案也未达到用户预期。
- 主要过程问题：在缺少可直接点击测试对象、未完成完整视觉验收的情况下，表现实现扩展到了专用 ViewAction、Shader、材质和粒子，修改范围偏大。

## 回退边界

本次只回退上述收集表现试做，保留以下已确认内容：

- 能量牌普通态彩虹牌底、喷罐花色和 Pile 暗态普通牌底资源配置。
- 染色炸弹目标牌资源及既有染色表现。
- `DyeingBombTargetFilter` 对低层牌补组选取的逻辑修复。
- 与本次表现试做无关的 Unity 自动生成改动和本地未跟踪文件。

## 回退结果

- 上述收集表现涉及的 5 个既有文件已恢复为当前分支 `HEAD` 内容。
- 2 个能量牌专用 LevelCollect C# 文件及其 `.meta` 已删除。
- `Energy/Material/` 下新增的 Shader、材质、`.meta` 和空目录已删除。
- 全仓检索已无 `EnergyLevelCollect`、`EnergyCollectVortex`、`PlayCollectExitAnimation`、`collectPaintParticle` 和收集缩放参数残留。
- `git diff --check` 通过；Unity 刷新后 `TileMatch.View.dll` 的时间晚于回退后的源码，Console 为 `0 error`。
- 最终工作区仍保留与本次回退无关的 `DyeingBombTargetFilter.cs`、`Dynamic.spriteatlas`、两个已暂存 UI Prefab 和本地未跟踪文件；未擅自处理。

## 后续再做时的前置条件

1. 先准备一关可直接点击的能量牌，不允许冰层或其他 Effect 截获点击。
2. 先用录屏或动画草图确认“牌底消失”和“花色起飞”的关键帧、时长与层级。
3. 优先用 Prefab 动画或美术序列帧做小范围原型；确认方向后再决定是否引入专用 Shader/ViewAction。
4. 验收至少覆盖：1.2 倍点击反馈、牌底消失轮廓、花色起飞衔接、目标落点、粒子层级以及中断/重连后的复位。
