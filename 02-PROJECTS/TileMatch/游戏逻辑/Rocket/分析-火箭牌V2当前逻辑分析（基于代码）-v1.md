## 一、生成规则（`RocketDepthStrategy.cs`）

### 1.1 生成数量计算

**代码位置**: `RocketDepthStrategy.GetRocketGroupCount()` (第117-126行)

```csharp
private static int GetRocketGroupCount(int normalGroupCount)
{
    int rocketGroupCount = 3;  // ⚠️ base=3 (不是文档说的 4)
    if (normalGroupCount > 25)
    {
        rocketGroupCount += (normalGroupCount - 25) / 5;
    }
    return rocketGroupCount;
}
```

**计算公式**:
```
rocketGroupCount = 3 + max(0, (normalGroupCount - 25) / 5)
```

**实际示例**:

| 普通牌组数 | 计算过程 | 火箭组数 | 火箭张数 |
|------------|---------|---------|---------|
| 20 | 3 + 0 | 3 | 9 |
| 25 | 3 + 0 | 3 | 9 |
| 30 | 3 + (30-25)/5 = 3 + 1 | 4 | 12 |
| 35 | 3 + (35-25)/5 = 3 + 2 | 5 | 15 |
| 40 | 3 + (40-25)/5 = 3 + 3 | 6 | 18 |

### 1.2 候选牌条件

**代码位置**: `RocketDepthStrategy.IsNormalCandidate()` (第90-115行)

```csharp
private static bool IsNormalCandidate(Tile tile)
{
    if (tile == null) return false;
    if (!tile.TileData.FromRandom) return false;  // 必须是随机生成的牌
    if (tile.TileType == TileType.Rocket || 
        tile.TileType == TileType.Golden || 
        tile.TileType == TileType.CandyBottle) return false;  // 排除特殊牌
    
    var tileGroup = tile.TileData.TileType.GetTileGroup();
    if (tileGroup == TileGroup.Blocker || 
        tileGroup == TileGroup.Collectable) return false;  // 排除 Blocker 和 Collectable
    
    return true;
}
```

**排除规则**:
- ❌ `FromRandom == false` (非随机生成的牌)
- ❌ `TileType.Rocket` (已是火箭)
- ❌ `TileType.Golden` (金牌)
- ❌ `TileType.CandyBottle` (糖果瓶)
- ❌ `TileGroup.Blocker` (障碍物)
- ❌ `TileGroup.Collectable` (可收集物)

### 1.3 深度分桶算法

**代码位置**: `RocketDepthStrategy.SplitByDepthBuckets()` (第185-213行)

```csharp
private static List<List<RocketCandidate>> SplitByDepthBuckets(List<RocketCandidate> candidates)
{
    // ⚠️ 使用向上取整
    int shallowEnd = (candidates.Count * 30 + 99) / 100;   // 前 30%
    int middleEnd = (candidates.Count * 60 + 99) / 100;    // 前 60%
    
    var buckets = new List<List<RocketCandidate>>
    {
        new(), // 桶0: 浅层 (前30%)
        new(), // 桶1: 中层 (30%-60%)
        new()  // 桶2: 深层 (剩余)
    };
    
    for (int i = 0; i < candidates.Count; i++)
    {
        if (i < shallowEnd)
            buckets[0].Add(candidates[i]);
        else if (i < middleEnd)
            buckets[1].Add(candidates[i]);
        else
            buckets[2].Add(candidates[i]);
    }
    
    return buckets;
}
```

**分桶规则**:
- 候选牌已按深度排序（浅→深）
- **桶0 (浅层)**: 前 30%（向上取整）
- **桶1 (中层)**: 30%-60%（向上取整）
- **桶2 (深层)**: 剩余部分

**示例**: 如果候选牌有 10 张
- 浅层: `(10*30+99)/100 = 12/100 = 0?` ⚠️ **需要验证**
- 实际计算: `(10*30+99)/100 = 399/100 = 3` (向上取整)
- 所以: 浅层=3张, 中层=3张, 深层=4张

### 1.4 连胜动态调节

**代码位置**: `RocketDepthStrategy.SelectRocketCandidates()` (第163-183行)

```csharp
private List<RocketCandidate> SelectRocketCandidates(
    List<RocketCandidate> candidates, 
    int rocketGroupCount)
{
    var buckets = SplitByDepthBuckets(candidates);
    var selectedCandidates = new List<RocketCandidate>(rocketGroupCount * 3);
    var selectedIds = new HashSet<long>();
    
    // ⚠️ 关键：连胜调节
    int shallowGroupCount = _gameContext.DataBridge.WinStreakTimes <= 2 ? 2 : 1;
    shallowGroupCount = Math.Min(shallowGroupCount, rocketGroupCount);
    int middleGroupCount = rocketGroupCount - shallowGroupCount;
    
    // 1. 从浅层桶选 shallowGroupCount 组
    CollectGroups(selectedCandidates, selectedIds, buckets, shallowGroupCount, 0);
    
    // 2. 从中层桶选剩余组
    CollectGroups(selectedCandidates, selectedIds, buckets, middleGroupCount, 1);
    
    // 3. 不足时从所有桶补足
    int selectedGroupCount = selectedCandidates.Count / 3;
    if (selectedGroupCount < rocketGroupCount)
    {
        CollectGroups(selectedCandidates, selectedIds, buckets, 
                     rocketGroupCount - selectedGroupCount, 0);
    }
    
    return selectedCandidates;
}
```

**连胜调节规则**:

| `DataBridge.WinStreakTimes` | 浅层组数 | 中层组数 | 说明 |
|----------------------------|---------|---------|------|
| ≤ 2 | 2 组 | 剩余 | 正常分布，浅层多 |
| > 2 | 1 组 | 剩余 | 降低浅层密度 |

**⚠️ 注意**: 这里读取的是 `DataBridge.WinStreakTimes`，不是 `LevelRocketOpenWinTimes`！

### 1.5 Highlight 区兜底

**代码位置**: `RocketDepthStrategy.EnsureHighlightNotAllRocket()` (第301-343行)

**触发条件**: Highlight 区的牌**全部是火箭**

**处理流程**:

### 2.3 Lucky 判定逻辑

**代码位置**: `PrepareChainedAttackAction.IsLuckyRocket()` (第108-121行)

```csharp
private static bool IsLuckyRocket(TileMatchGameContext ctx)
{
    int probability = ctx.DataBridge != null ? ctx.DataBridge.RocketLuckyProbability : 0;
    
    if (probability <= 0) return false;   // 0% → 必不触发
    if (probability >= 100) return true;  // 100% → 必触发
    
    // 按概率判定
    return ctx.RandomService.Range(0, 100) < probability;
}
```

**判定时机**: 每次 Bar 内火箭三消时独立判定

**判定次数**: 每次火箭匹配都独立判定（不是全局一次）

## 三、Chain Rocket

### 3.1 触发条件

**代码位置**: `PrepareChainedAttackAction.AppendChainWaves()` (第123-181行)

**触发条件**: 主波或链式波的目标中，**每满 3 张火箭** → 触发 1 个链式源组

**关键代码**:

```csharp
int groupSize = GetChainTriggerGroupSize(ctx, config);  // 默认 3
// ...
var sourceGroup = new List<Tile>(groupSize);
for (int targetIndex = 0; targetIndex < wave.Targets.Count; targetIndex++)
{
    var targetData = wave.Targets[targetIndex].Tile;
    if (targetData.TileType != config.chainTriggerTileType) continue;  // 不是火箭则跳过
    
    sourceGroup.Add(chainSource);
    if (sourceGroup.Count < groupSize) continue;  // 不足 3 张，继续收集
    
    // 满 3 张 → 创建链式波

    {

    }
    sourceGroup.Clear();
}
```

### 3.2 波次规则

**配置参数** (来自 `Rocket.json`):

```json
{
  "MaxChainWave": 2,              // 最大额外链式波次
  "ChainMaxTarget": 6,            // 每个链式源组最多攻击 6 个目标
  "ChainTriggerTileType": 5000,   // 触发连锁的牌型 (Rocket)
  "ChainTargetFilter": "RocketChain"

```

**波次定义**:

| 波次 | WaveIndex | 触发条件 | 说明 |
|------|-----------|---------|------|
| 主波 | 0 | 玩家匹配 3 张火箭 | 初始攻击 |
| 链式波 1 | 1 | 主波命中 ≥3 张火箭 | 第一层连锁 |
| 链式波 2 | 2 | 链式波 1 命中 ≥3 张火箭 | 第二层连锁 (最后一层) |

**⚠️ 关键**: 最多 2 层链式 (MaxChainWave=2)

### 3.3 主波目标筛选 (`RocketPrimaryTargetFilter`)

**代码位置**: `RocketPrimaryTargetFilter.cs` (第7-40行)

**继承关系**: `RocketPrimaryTargetFilter` → `RocketCustomTargetFilterV2` → `TargetFilter`

**筛选逻辑**:

1. **主选择循环** (在 `RocketCustomTargetFilterV2.FilterTiles()` 中):
   - 尝试选择同类型牌组（3张同类型）
   - 优先级: Highlight → Bar → OverBar
   - 如果找到完整组（3张）→ 加入目标
   - 如果找到部分组（<3张）→ 标记为已处理，不再尝试

2. **Fallback 到火箭** (在 `RocketCustomTargetFilterV2.CollectRocketTiles()` 中):
   - 如果目标数不足 → 调用 `CollectRocketTiles()`
   - **⚠️ 关键发现**: Fallback 逻辑**仍然存在**！
   - `RocketPrimaryTargetFilter` 重写了 `ShouldSkipFallbackRocket()`:
     ```csharp
     protected override bool ShouldSkipFallbackRocket(
         Tile tile, HashSet<Tile> targetTiles, HashSet<Tile> processedTiles)
     {
         return targetTiles.Contains(tile) || processedTiles.Contains(tile);
     }
     ```
   - 这意味着：已选中的火箭和已处理的火箭会被跳过，但其他火箭仍可被选中

3. **`IsTileGroupAvailable()` 重写**:
   ```csharp
   protected override bool IsTileGroupAvailable(Tile tile)
   {
       var tileGroup = tile.TileType.GetTileGroup();
       if (tileGroup == TileGroup.Blocker && tile.TileType != TileType.Rocket)
           return false;  // Blocker 组中只有 Rocket 可选
       
       if (tileGroup == TileGroup.Collectable)
           return false;  // Collectable 不可选
       
       return true;  // 其他组（包括 Normal）都可选
   }
   ```

**实际行为**:
- 火箭**可以**在主选择循环中被选中（如果在 Blocker 组中，或者其他组中恰好有 3 张同类型火箭）
- 如果主选择循环选不够 → **仍会 fallback 到 `CollectRocketTiles()` 选火箭**

**⚠️ 与文档差异**: 文档说"Rocket 不再只通过 fallback CollectRocketTiles 被选中"，但代码显示 fallback 仍存在。

### 3.4 链式波目标筛选 (`RocketChainTargetFilter`)

**代码位置**: `RocketChainTargetFilter.cs` (第10-163行)

**筛选逻辑**:

1. **第一轮：只选普通牌** (`collectRocket=false`):
   ```csharp
   CollectFromPools(targetTiles, selectedTiles, requestedTarget, 
                   false, eligible, ...);
   ```

2. **第二轮：普通牌不足时，允许选火箭** (`collectRocket=true`):
   ```csharp
   if (targetTiles.Count < requestedTarget)
   {
       CollectFromPools(targetTiles, selectedTiles, requestedTarget, 
                       true, eligible, ...);
   }
   ```

3. **`IsAvailable()` 判断**:
   ```csharp
   private static bool IsAvailable(Tile tile, bool collectRocket, ...)
   {
       if (tile.TileData.LockState == LockState.Locked) return false;
       if (tile.TileData.State == TileState.WillDestroy) return false;
       
       if (collectRocket)
       {
           // 第二轮：只选 Rocket
           if (tile.TileType != TileType.Rocket) return false;
       }
       else
       {
           // 第一轮：只选普通牌
           if (!IsNormalTarget(tile)) return false;
       }
       
       return true;
   }
   ```

4. **`IsNormalTarget()` 定义**:
   ```csharp
   private static bool IsNormalTarget(Tile tile)
   {
       if (tile.TileType.GetTileGroup() != TileGroup.Normal) return false;
       if (tile.TileType == TileType.Golden || 
           tile.TileType == TileType.CandyBottle || 
           tile.TileType == TileType.Rocket) return false;
       return true;
   }
   ```

**筛选规则总结**:
- ✅ 优先选 Normal 组的牌（排除 Golden、CandyBottle、Rocket）
- ✅ 普通牌不足时允许选 Rocket
- ❌ 排除 Locked 牌
- ❌ 排除 WillDestroy 牌

### 3.5 事件抑制

**问题**: 链式命中的火箭被销毁时，会触发 `Rocket_Attack_When_Direct_TileDestroyed` (邻居 Side Attack)

**解决方案**: `TileDestroyedEventData.SuppressDirectTileDestroyedAttack`

**代码位置**: `PrepareChainedAttackAction.CreateWave()` (第249-252行)

```csharp
DestroyContext = target.TileType == config.chainTriggerTileType
    ? new TileDestroyedEventData { SuppressDirectTileDestroyedAttack = true }
    : null
```

**抑制 Condition**:

**代码位置**: `DirectTileDestroyedAttackNotSuppressedCondition.cs`

```csharp
public bool Evaluate(IEntity self, IContext ctx, in EventData eventData, ConditionConfig conditionConfig)
{
    if (eventData.Arguments?.Extra is TileDestroyedEventData destroyContext)
    {
        if (destroyContext.SuppressDirectTileDestroyedAttack)
            return false;  // 抑制邻居攻击
    }
    
    return true;  // 允许触发
}
```

**配置** (`Rocket.json`):

```json
{
  "Event": "TileDestroyed",
  "Condition": [
    {
      "ConditionType": "DirectTileDestroyedAttackNotSuppressed"
    }
  ],
  "Action": {
    "ActionType": "Attack",
    "TargetFilter": "Side"
  }
}
```

**⚠️ 注意**: `Rocket_TileDestroyed → DestroyTile` 不增加该 Condition，保证链式命中的火箭仍正常销毁。

## 四、预计算机制

### 4.1 逻辑层预计算

**关键设计**: V2 在逻辑层**一次性预计算所有波次**，而不是在表现层运行时逐层计算。

**代码位置**: `PrepareChainedAttackAction.Execute()` (第98-102行)

```csharp
// 主波创建完成后，递归预计算所有链式波
for (int waveIndex = 0; waveIndex < data.Waves.Count; waveIndex++)
{
    var wave = data.Waves[waveIndex];
    AppendChainWaves(ctx, config, wave, matchTiles, selectedTiles, data.Waves);
}
```

**算法流程**:
1. 创建主波 (WaveIndex=0)
2. 调用 `AppendChainWaves()` 检查主波是否触发链式
3. 如果触发 → 创建链式波 1 (WaveIndex=1)
4. 循环检查新创建的波是否触发下一级链式
5. 直到没有新波创建，或达到 `MaxChainWave`

**⚠️ 关键**: 使用 `for` 循环而不是 `foreach`，因为 `data.Waves` 在循环中会动态增加！

### 4.2 目标锁定

**代码位置**: `PrepareChainedAttackAction.CreateWave()` (第243行)

```csharp
target.SetLockState(LockState.Locked, LockSource.Destroy);
```

**锁定目的**:
1. 防止同一张牌被多个波次选中
2. 防止牌在被攻击前被消除

**跨波次去重**:
```csharp
var selectedTiles = new HashSet<TileData>();  // 跨波次去重
```

在 `CreateWave()` 中：
```csharp
if (!selectedTiles.Add(target.TileData))
{
    continue;  // 已选中，跳过
}
```
