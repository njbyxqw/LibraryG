# 障碍牌类型全览

障碍牌 = TileType >= 5000 的特殊 Tile。**独立占据棋盘格子，可进 Bar，有序列子牌体系。**

## Direction 变体

| Suffix | 方向 | 容器示例 |
|--------|------|---------|
| `Up` | 朝上 | ShellBoxUp = 上方是开口 |
| `Down` | 朝下 | ShellBoxDown = 下方是开口 |
| `Left` | 朝左 | ShellBoxLeft = 左边是开口 |
| `Right` | 朝右 | ShellBoxRight = 右边是开口 |
