## V4（2026-07-16 双因子评分重构）

### 评分公式
```
指标得分 = (P5/P95归一化 × 0.6 + Δ调整 × 0.4) × 权重
Δ调整 = 查4档桶: |Δ|≤波动→1.0 / ≤轻→0.75 / ≤中→0.5 / >重→0
恶化扣分，改善镜像加分
V1 Δ调整恒=1.0（无对比），V2 查桶
Δ = V2质量分 - V1质量分（纯减法）
```

### 策略变更 vs V3
- **去掉全部 Log 变换**：A/C 两组数据验证，6 指标右尾比均 ≤3，Log 是过度设计
- **纯 P5/P95 归一化**：统一 min/max 来自两组合并计算
- **行色回归纯标签驱动**：清零+Δ≥0→绿，新增标签→红，其余无色
- **双因子嵌在指标层**：每个指标的评分同时考虑排名和变化量，而非贴在最终分数外

|------|:--:|:--:|:--:|:--:|:--:|:--:|
| 流失率 | 0.20 | 1.0 | 2.5 | >2.5 | ↓ | 0/25/50/100 |

## V3（2026-07-14 晚间逻辑纠正）

### 2026-07-14 晚间逻辑纠正
- **统一归一化**：两组数据合并 min/max，Δ=V2-V1 反映绝对值变化（此前为独立归一化，同关不同配置场景下反直觉）
- **基准方向**：V1=基准（老关卡），V2=对比（新关卡），Δ=V2-V1
- **行色综合**：标签×Δ 判定——标签清零+Δ≥0 才标绿，标签清零但Δ<0 不标绿
- **权重恢复**：renW() 刷新 DOM 滑块
- **排序标签**：改为"Δ 降序(改善→恶化)"

## 对比指标分析

| 指标 | 标签可靠性 | 备注 |
|------|----------|------|
| 流失率 | 最可靠 | 无歧义，超标即使改善也需关注 |
| 难度 | 中等 | 阈值外两个都标，需看 Δ 辅助判断 |
| 变异系数 | 中等 | 同上。1.9→1.4 是进步但两个都标 |
| 人均消耗 | 需注意 | 方向反转：替换工具"低=问题"，对比里消耗↑ 是改善 |
| 复活转化 | 弱信号 | 转化低可能是关卡简单不需要复活 |
| 失败剩余率(首次) | 一般 | 越小越好，标签"剩余率高"需适应 |
