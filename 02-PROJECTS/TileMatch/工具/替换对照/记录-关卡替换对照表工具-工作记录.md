# 关卡替换对照表工具 — 工作记录

> 功能报告：[[报告-关卡替换对照表工具]]

---

## 2026-07-13 — V1 初始构建

### 功能
- A/B 双文件 Excel 上传（SheetJS XLSX，`header:1` 解析），B 集可选
- 6 维归一化加权评分：流失率(40%↓) / 体验方差(25%↓) / 难度(15%↓) / 人均消耗(10%↑) / 复活转化(5%↑) / 失败剩余率(5%↓)
- 权重滑块可调（↑↓方向按钮 + range + number 联动），合计实时显示
- 基础标准 3 项 + 进阶标准 3 项标注线，仅高亮不硬过滤
- B 候选按难度差距排序 Top 5，显示候选难度+流失率
- 操作列三态：待处理(替换/跳过) → 已替换(绿标) → 已跳过(黄标)
- 点击候选选中(蓝框高亮) → 点替换确认，无需弹窗
- 重复替换检测：同一 B 关多次使用状态栏红字警告
- 导出对照表 CSV + 关卡详情面板

### Bug 修复

**B 文件行数虚高**
- 现象：上传 B.xlsx 显示 553 行，实际 481 行
- 原因：末尾 72 行前 7 列为 None，后 50 列为公式残留 0 值，`Object.values().some(v=>v!=='')` 检查通过
- 修复：按 Level 列判空跳过无效行

**权重箭头无反应**
- 原因：`ren()` 函数定义在 IIFE 闭包内，onclick 无法访问
- 修复：`window.renW = ren` 暴露到全局

**按钮太挤**
- 将 ✓/跳 改为全文字"替换"/"跳过"，min-width:26px

### 阈值校订
全部默认值重新用 A 数据分位数验证：

| 指标 | 默认值 | 依据 | 来源 |
|------|--------|------|------|
| 流失率 | 1.5% | P85 | R2 标准 |
| 难度 | 3.0 | P95 | B 最高 2.95 |
| 变异系数 | 1.2 | P88 | R2 标准 |
| 人均消耗 | 200 | P25 | 均值 351 |
| 复活转化率 | 15% | P25 | 均值 24.5% |
| 失败剩余率 | 0.44 | P75 | 首次失败剩余率，越小越好 |

### 失败剩余率方向修正
- 原：↑越大越好（V3 解释为"差一步"感，复活意愿高）
- 改：↓越小越好（失败时剩余牌越少=越接近通关=体验越好）
- 数据列从 `平均失败剩余率` 改为 `首次失败剩余率`

### 关键发现
- 新手期 1-20 关：流失高但难度 1.04，自然漏斗非关卡问题
- 最佳替换区：51-200，B 候选充沛
- 挫败尖刺：Lv 177(难度2.52) / 186(3.52,流失5.89%) / 190(2.65)
- R1 优先替换 15 关
