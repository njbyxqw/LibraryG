## 核心差异

### 替换工具独有
1. **B 集候选匹配**：按难度差排序 Top5，显示候选的难度+流失率
2. **替换/跳过操作**：三态按钮（待处理→已替换/已跳过）
3. **重复替换检测**：同一 B 关多次使用时红色警告
4. **唯一需要人工交互**：分析 V3 和对比 V2 都是纯查看

### 对比工具独有
1. **双版本独立评分**：两组数据各自归一化后逐关 diff
2. **标签驱动分类**：四分类（已修复/改善未修复/新问题/正常）
3. **双列 V1→V2 diff**：每项指标显示 `V1值→V2值 ↑↓`
4. **自定义对比指标**：从列名下拉选，值嵌入 level 对象
5. **localStorage 持久化**：刷新秒恢复

### 分析工具独有
1. **动态增删指标**：内置 6 项可去掉，额外指标可从列名添加
2. **唯一支持单文件**：不需要两个版本
3. **当前在桌面未集成到工作区**

## 共享模块（集成关键）

对比三个文件，以下逻辑完全一致或仅微小差异：

### 可直接复用

| 模块 | 行数 | 涉及功能 |
|------|------|---------|
| `scoreDataset()` | ~70行 | 归一化评分 + 列名匹配 + 阈值标注 |
| 上传解析（SheetJS） | ~40行 | 文件读取 + header:1解析 + 空白过滤 |
| 权重 UI 组件 | ~60行 | 滑块 + number + ↑↓ 联动 + 合计 |
| 阈值面板 | ~20行 | 6 项标准输入 |
| 筛选/排序/搜索 | ~30行 | 下拉 + checkbox + text input |
| CSV 导出 | ~20行 | Blob + download |
| localStorage 持久化 | ~30行 | save/restore 逻辑 |
| 全局 CSS 变量 | ~40行 | 颜色/字体/圆角 |

### 需适配层

| 差异点 | 说明 |
|--------|------|
| 数据流 | 对比传入 `datasets[]`，替换传入 A/B 两个变量 |
| 表格渲染 | 三个工具列完全不同，各自实现 |
| 操作交互 | 替换要按钮+状态，其他只读 |
| 分析结果结构 | 替换用 `map0/map1`，对比用 `levels[].r0/.r1` |

## 集成方案

### 方案 A：共享内核 + 三页面（推荐）

```
共享模块（单独 .js 或 <script> 块）
├── 上传引擎 (SheetJS)
├── 评分引擎 (scoreDataset)
├── UI 组件 (权重滑块、阈值面板)
├── 持久化 (localStorage)
└── 公共样式 (CSS variables)

三个视图（各自 <script> 块）
├── 替换视图：候选匹配 + 替换操作
├── 对比视图：双列 diff + 标注
└── 分析视图：动态指标列表
```

- 优点：代码不重复，各自视图独立维护
- 缺点：三份 HTML 需同步更新共享模块

### 方案 B：单文件三 Tab

```
关卡数据工具.html
├── Tab 1：分析诊断
├── Tab 2：替换对照
└── Tab 3：版本对比
```

- 优点：一个入口，状态共享，无需切换页面
- 缺点：单文件过大（当前对比已 33KB），Tab 切换时数据流复杂

### 建议
先用方案 A，从对比工具提取共享模块（它功能最全），让替换工具引用。分析工具最后迁入。稳定后再评估是否合并为方案 B。
