# 关卡数据分析工具

> 纯前端 HTML 工具，上传关卡数据 Excel 后自动进行难度分析、指标对比、曲线图表查询，辅助关卡设计决策。历经 v1 → v2 → v3 三次迭代。

---

## 一、工具概述

关卡数据分析工具是一个独立的 HTML 页面，无需后端服务，直接在浏览器中运行。策划人员上传关卡数据 Excel 文件，工具自动计算难度评分、生成可视化图表和策划洞察。

### 文件位置

| 版本 | 路径 | 大小 |
|------|------|------|
| v1 | `D:\meatloaf_client01\2026-06-29-11-45-23\关卡数据分析工具.html` | 42 KB |
| v2 | `D:\meatloaf_client01\2026-06-29-11-45-23\关卡数据分析工具_v2.html` | 47 KB |
| v3 | `D:\meatloaf_client01\2026-06-29-11-45-23\关卡数据分析工具_v3.html` | 48 KB |

### 技术栈

- **纯 HTML/CSS/JS**：无构建工具，单文件部署
- **SheetJS (xlsx.full.min.js)**：解析 Excel 文件
- **CSS 变量主题**：统一设计语言，支持快速换色

## 二、版本演进

### 2.1 V1 — 基础功能

**核心能力**：
- Excel 文件上传（拖拽 + 点击）
- 基础数据表格展示
- 简单的指标计算

**局限**：
- 指标配置固定，无法自定义
- 缺乏难度评分机制
- 无策划洞察

### 2.2 V2 — 指标配置 + 难度评分

**新增功能**：
- 可配置指标列表（添加/删除指标）
- 指标方向设置（↑ 越高越难 / ↓ 越低越难）
- 指标权重调节（滑块 + 数字输入）
- 难度综合评分（加权计算）
- 数据表格增强：排名、评分条形图

**改进**：
- 更丰富的表格展示（排名徽章、评分可视化）
- 导出功能

### 2.3 V3 — 策划洞察 + 可视化仪表盘

**新增功能**：
- **总览卡片**：4 列概览（关卡总数、平均分、最高分、最低分）
- **指标对比卡片**：3 列指标对比，含 good/warn/bad 徽章标注
- **策划洞察卡片**：自动生成文字洞察，标注关键关注点
- **关卡列表 + 复制按钮**：快速复制异常关卡编号
- **曲线图表查询**：按指标生成趋势曲线

**UI 优化**：
- 深色顶栏（sticky 定位）
- 卡片式布局（圆角 + 阴影）
- 响应式网格布局

## 三、V3 功能详解

### 3.1 数据上传

- **拖拽上传**：支持拖拽 Excel 文件到上传区域
- **点击上传**：点击上传区域选择文件
- **格式要求**：`.xlsx` / `.xls` 格式

### 3.2 指标配置

| 配置项 | 说明 |
|--------|------|
| 指标选择 | 从数据列中选择参与评分的指标 |
| 方向设置 | `↑` 越高越难 / `↓` 越低越难 |
| 权重调节 | 0-100 滑块，支持手动输入 |
| 锁定指标 | 锁定后不可删除 |
| 添加/删除 | 动态增删指标行 |

### 3.3 仪表盘

#### 总览卡片（4 列）

| 卡片 | 内容 | 颜色 |
|------|------|------|
| 关卡总数 | 数据行数 | 蓝色 |
| 平均难度分 | 加权平均 | 绿色 |
| 最高难度分 | 最大值 | 琥珀色 |
| 最低难度分 | 最小值 | 紫色 |

#### 指标对比卡片（3 列）

- 每张卡片展示一个指标的分段统计
- `good` / `warn` / `bad` 三色徽章标注
- 横向条形图可视化分布
- 底部脚注显示统计细节

#### 策划洞察卡片（3 列）

- 自动识别异常关卡（难度过高/过低）
- 生成文字洞察，标注关键数字
- 彩色标签标注关注级别（蓝/绿/琥珀/紫）

### 3.4 数据表格

| 列 | 说明 |
|----|------|
| 排名 | 难度排名（1/2/3 特殊样式） |
| 关卡编号 | 蓝色标签 + R/L 徽章 |
| 各指标值 | 数值 + 迷你条形图 |
| 难度评分 | 蓝色数字 + 进度条 |
| 评价 | 绿/红/灰/琥珀色文字 |

### 3.5 导出功能

- 导出分析结果为 Excel

## 四、难度评分算法

### 4.1 计算流程

```
1. 对每个指标，根据方向（↑/↓）进行归一化
   - ↑ 方向：(value - min) / (max - min)
   - ↓ 方向：(max - value) / (max - min)

2. 加权求和
   score = Σ(normalized_i × weight_i) / Σ(weight_i)

3. 输出 0-100 分
```

### 4.2 评价标准

| 评分区间 | 评价 | 颜色 |
|----------|------|------|
| ≥ 80 | 困难 | 红色 |
| 60-79 | 适中 | 琥珀色 |
| 40-59 | 正常 | 灰色 |
| < 40 | 简单 | 绿色 |

## 六、使用方法

1. 用浏览器打开 `关卡数据分析工具_v3.html`
2. 上传关卡数据 Excel 文件
3. 在设置区域配置指标（选择指标、设置方向、调节权重）
4. 查看仪表盘和策划洞察
5. 在数据表格中查看详细排名
6. 可选：导出分析结果
