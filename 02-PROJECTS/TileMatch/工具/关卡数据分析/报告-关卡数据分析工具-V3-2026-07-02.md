## 二、V3 新增功能

### 2.1 总览仪表盘

4 列总览卡片，一眼掌握全局：

| 卡片 | 计算方式 | 颜色标识 |
|------|---------|----------|
| 关卡总数 | 数据行数 | 蓝色 |
| 平均难度分 | 加权评分均值 | 绿色 |
| 最高难度分 | 加权评分最大值 | 琥珀色 |
| 最低难度分 | 加权评分最小值 | 紫色 |

### 2.2 指标对比卡片

3 列布局，每个卡片展示一个指标的分段统计：

- **good / warn / bad** 三色徽章标注各分段
- 横向条形图可视化分段分布
- 底部脚注显示统计细节（均值、中位数等）

### 2.3 策划洞察卡片

3 列布局，自动生成文字洞察：

- **异常识别**：自动识别难度过高/过低的关卡
- **文字洞察**：生成自然语言描述，标注关键数字
- **关注级别标签**：蓝色（信息）、绿色（正常）、琥珀色（关注）、紫色（异常）
- **关卡编号列表**：异常关卡编号以标签形式展示，支持一键复制

### 2.4 关卡列表 + 复制按钮

- 异常关卡编号以蓝色标签展示
- 点击「复制」按钮一键复制关卡编号列表
- 方便粘贴到其他工具中进一步处理

### 2.5 曲线图表查询

- 按指标生成趋势曲线
- 支持多指标叠加对比
- X 轴：关卡编号，Y 轴：指标值

### 3.2 难度评分算法

```javascript
// 1. 归一化：根据方向（↑/↓）将指标值映射到 0-1
function normalize(value, min, max, direction) {
  if (direction === 'up') return (value - min) / (max - min);
  return (max - value) / (max - min);
}

// 2. 加权求和
function calcScore(metrics, weights, directions) {
  let sum = 0, totalWeight = 0;
  for (let i = 0; i < metrics.length; i++) {
    const norm = normalize(metrics[i].value, metrics[i].min, metrics[i].max, directions[i]);
    sum += norm * weights[i];
    totalWeight += weights[i];
  }
  return (sum / totalWeight) * 100;  // 输出 0-100 分
}
```

  const insights = [];
  
  // 1. 难度过高关卡（score >= 80）
  const hardLevels = data.filter((d, i) => scores[i] >= 80);
  if (hardLevels.length > 0) {
    insights.push({
      type: 'warn',
      text: `检测到 ${hardLevels.length} 个高难度关卡`,
      levels: hardLevels.map(d => d.levelId)

## 四、使用方法

### 4.1 快速开始

1. 用浏览器打开 `关卡数据分析工具_v3.html`
2. 拖拽或点击上传关卡数据 Excel 文件
3. 等待解析完成，进入设置页面

### 4.2 指标配置

1. 在设置区域查看自动识别的指标列表
2. 点击「添加指标」选择参与评分的指标
3. 为每个指标设置方向（↑ 越高越难 / ↓ 越低越难）
4. 调节权重滑块（0-100）
5. 可锁定重要指标防止误删

### 4.3 查看分析结果

1. **总览卡片**：快速了解全局难度分布
2. **指标对比卡片**：查看各指标分段统计
3. **策划洞察卡片**：阅读自动生成的洞察，点击复制异常关卡编号
4. **数据表格**：查看每个关卡的详细评分和排名
5. 点击「导出」可将结果保存为 Excel

### 4.4 数据格式要求

Excel 文件需包含以下列（列名不强制，工具会自动识别）：
- 关卡编号（如 `level_id`、`关卡ID`）
- 各项指标数据列（数值类型）
