### 磁盘路径
```
D:\meatloaf_client01\client\Assets\Game\TileV2\Res\Game\GameCore\Prefab\TileView\
```

### 关键文件
| Prefab | 用途 |
|--------|------|
| `Tile C{color}T{idx}.prefab` | 普通花色牌（外部引用，仅 .meta 在 Res/ 内） |
| `Tile Base.prefab` | Tile 基类 Prefab |
| `Butterfly/Prefab/Tile Butterfly.prefab` | 蝴蝶牌 |
| `Flip/Prefab/Tile Flip.prefab` | Flip 翻转牌 |
| `ShellBox/Prefab/Tile ShellBox_*.prefab` | 贝壳盒 |
| `Rocket/Prefab/SpecialTile_Rocket.prefab` | 火箭牌 |
| `MagicBox/Prefab/Tile MagicBox.prefab` | 魔法盒 |

### 加载链路
```
TileViewService.CreateTileViewFromData()
  → ResourceLoadService.LoadTilePrefab(TileType)
    → TileAssetConfigProvider.TryGetTilePrefabPath()
      → TileBreakEffectCfg.tilePrefabPath
      → TileBlockerCfg.prefabPath
    → xasset.Asset.Load(prefabPath)           // 运行时
    → AssetDatabase.LoadAssetAtPath           // 编辑器
```

### 配置表
| 表 | 代码路径 | 关键字段 |
|----|---------|---------|
| `TileBreakEffectCfg` | `Scripts/Config/TableConfig/TileBreakEffectCfg.cs` | `tilePrefabPath`, `effectPrefabPath`, `effectName` |
| `TileBlockerCfg` | `Scripts/Config/TileBlockerCfg/TileBlockerCfg.cs` | `prefabPath`, `effectPrefabPath`, `effectName`, `type` |

### 中枢类
- `TileAssetConfigProvider` — `Scripts/Config/TileAsset/TileAssetConfigProvider.cs`
  - 合并两张配置表，提供 `TryGetTilePrefabPath()` / `TryGetEffectPrefabPath()`

### 背景原始图（PNG）

```
D:\meatloaf_client01\client\Assets\Game\TileV2\Res\Game\GameCore\Texture\Backgrounds\
```
命名：`bg00.png`, `bg01.png`, `bg02.png`, `bg101~104.png`, `Bonus.png` 等

### 背景选择优先级
加载入口：`TileMatchViewController.LoadBackgroundView()`

```
1. LevelConfig.BackgroundId > 0  →  LevelBgConfig.PrefabPath（自定义背景）
2. LevelType == Bonus           →  ConfigData.BonusBackground（固定）
3. Proxy.GetOverrideBackground() →  运营覆盖
4. LevelHard 难度默认            →  ConfigData.BackgroundByDifficulty
```

### 默认背景常量（ConfigData.cs）

|------|------|
| Normal | `Res/Game/GameCore/Prefab/BackgroundView/Background110.prefab` |

| DifficultPlus | `Res/Game/GameCore/Prefab/BackgroundView/Background3.prefab` |
| Bonus | `Res/Game/GameCore/Prefab/BackgroundView/BackgroundBonus.prefab` |

## 资源加载中枢

`TileResourceHub`（位于 `Game.TileShared.Scripts.Util` 命名空间）：
- `TileResourceHub.CombinePath(relativePath)` — 拼接完整资源路径
- `TileResourceHub.LoadAsset<T>(path, owner)` — 加载资源
- 编辑器下走 `AssetDatabase.LoadAssetAtPath`，运行时走 `xasset.Asset.Load`
