# TileMatch 项目概览

## 基本信息

- **项目类型**: 消除类游戏 (Match-3)
- **引擎**: Unity (C#)
- **代码仓库**: `D:\meatloaf_client01\Claw`
- **架构**: MVC + Command + Strategy + Observer
- **配置序列化**: Protobuf (.bytes)
- **程序集管理**: asmdef
- **依赖**: BettaFramework / BettaSDK

## 核心模块

### 关卡编辑器 (TileV2)
- 基于 UGUI Canvas + Prefab 构建
- 多阶段白盒工作流: Phase1(tile空间布局) → 后续阶段(花色/Effect/Pile/难度调控)
- LocalExtensions 本地扩展系统 (反射注入 + [InitializeOnLoad])

### 游戏逻辑
- SuitCase 行李箱卡牌调控机制
- FirstNHighlight 策略 (Count=3)
- 子牌保护逻辑
- Rocket 火箭牌模块

### 工具链
- LevelFileMigrationTool (v3.4) — 关卡文件迁移（通配符搜索、范围筛选）
- TileTypeGroupConfig — Protobuf 配置管理
- 打点系统

## 工作空间

- **LocalExtensions 目录**: 零存储动态绑定，不修改主代码
- **工作空间产物**: `.workbuddy/`, `workbuddy_archives/`
