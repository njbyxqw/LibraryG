# 知识库文档顺序索引

> 按 `cat_order` 集中展示全库顺序（编号方案见 [[知识库编号方案_整合v1_2026-07-08]]）。
> 顺序不进 [[_MOC]]，MOC 只做导航；本页专管排序。
> 需安装并启用 Obsidian **Dataview** 插件后下方表格自动渲染。

```dataview
TABLE cat_order AS "类内序", date AS "进库时间", status AS "状态"
FROM "02-PROJECTS/TileMatch"
WHERE cat_order
SORT file.folder ASC, cat_order ASC
```
