## 序列容器深度梳理

### 分析范围
- 读取了 `SequenceConstraintHelper.cs` 了解约束策略注册（Flip/CardBox/SuitCase = FlipProfile）
- 扫描了 30+ 个关卡 JSON 文件，提取所有使用 SequenceCount/Sequences 的 TileType
- 对比了 V1 和 V2 两种花色分配策略的代码差异

### 发现与更新
1. **序列容器共 11 种**，分 A/B 两类：
   - A 类（有去重+保护）：Flip(5110)、CardBox(5140/未上线)、SuitCase(5130-5131/未上线)
   - B 类（无约束）：MagicBox(5010)、ShellBox×4(5030-5033)、JokerFlip(5150)、Thief(5160)
2. **V1 统一打乱**：普通牌和序列牌共享一个花色池，`targetCount = count1 + count2`，一次 `ShuffleTileType`
3. **V2 分池打乱**：`shufflePool`（普通深池 Fisher-Yates）、`deterministicPool`（浅池不打乱）、`sequencePool`（序列池单独 Fisher-Yates）
4. 序列子牌与普通 Tile 的区别：运行时动态追加、共享容器 Position、SequenceSource 指向父级索引
5. 更新了 `障碍Tile生成与序列逻辑梳理.md`，新增"四、序列容器类型全览"和"五、打乱是统一还是分开"两节

### 发现
1. **Flip**: Rotate 循环左移 + FirstNHighlight(1) 逐张暴露。关键行为：点击取牌触发 Rotate，队首移到队尾，新队首高亮
2. **CardBox**: 不做序列变换。Life=6 护盾，打 0 血开盒（FirstNVisible→FirstNHighlight），开盒后子牌可交互。有死局保护（无牌可交互时自动破盒）
3. **SuitCase**: 不做序列变换。大格子(3x1/1x3)，变 Highlight 脱盖，一次性暴露 3 张
4. 三者共用 FlipProfile（Prefer 花色去重 + DDA 保护子牌）
5. 更新文档新增"七、A 类容器详细行为解析"

## Deadlock 死局逻辑确认

### 范围
- 用户回忆了死局判定条件（手牌区剩1格 + 下一步无法消除），要求验证
- 读取了核心文件：InevitableDeathJudge.cs、TileMatchGameLogic.Deadlock.cs、TileMatchGameLogic.Event.cs、TileMatchGameLogic.Prop.cs、TileMatchGameLogic.Logger.cs、TaDataManager.cs、Bar.cs、InLevelDDAV1Strategy.cs

### 确认结论
1. **判定条件无误**：`InevitableDeathJudge.IsDeadlock()` 中，当 `UnmatchedCount > CurrentCapacity - 2`(即 remainingCapacity <= 1) 时才判死局，然后遍历所有可点击牌检查单张/双张消除可能性
2. **上报路径确认**：`prop_used`（道具使用，含 `deadlock_times` + `is_deadlock`）、`lv_end`/`lv_revive`（关卡结束/复活，含 `deadlock_times`）、`add_moves_show`（复活弹窗）
3. **状态更新触发点**：AddingToBarByClick、BarMatched、LevelPrePropFinished、LevelFailed、LevelRevived、AfterShuffle、UseProp()成功后

## Deadlock 死局深度分析第二轮

### 范围
- 进一步排查了 BarData.cs 中 MaxCapacity/CurrentCapacity 始终相等，推出 remainingCapacity = CurrentCapacity - Tiles.Count
- 发现 `InevitableDeathJudge.cs` 第 76 行 `remainingCapacity >= 2` 分支是死代码：入口条件 `UnmatchedCount <= CurrentCapacity - 2` 早已过滤掉所有 remainingCapacity >= 2 的情况
- 讨论了 deadlock_duration（死局持续时长）作为新字段附在现有事件上，不需要独立事件
- 确认 deadlock_times 即死局序号，无需额外 index
