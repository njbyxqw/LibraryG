# 2026年06月02日 星期日#

## 2026-06-02 曲线优化 - 动画曲线代码溯源

### 任务
查找游戏中三个关键动画曲线的代码位置和参数：
1. 金牌收集动画曲线
2. 火箭牌打击动画曲线
3. 普通tile到手牌区动画曲线

### 分析结果

#### 1. 金牌收集曲线
- **核心文件**: GameExtend.DOLerpMove() (CatmullRom三阶贝塞尔) + ParticleCase.DoMove() + GoldenCollectView.PlayCollectAnimation()
- **曲线类型**: 贝塞尔路径，CatmullRom，控制点 X*0.618, Y*0.88(右)/Y*0.328(左)
- **缓动**: 默认 Ease.Linear (DoMove) / Ease.OutCubic (DOLerpMove)
- **时间**: 0.8s
- **特殊**: DoGoldMove 含1.0s缩放脉冲+旋转变形

#### 2. 火箭牌打击曲线
- **核心文件**: RocketViewAction.GetWayPoints() (三阶贝塞尔20采样点) → ParticleCase.DoPath() → DOPath(PathType.Linear, TopDown2D)
- **曲线类型**: 4控制点三阶贝塞尔，X偏移±1.8，Y比例 2/3 和 1/3
- **缓动**: Ease.InOutQuad, isLookAt=true
- **时间**: 0.75~0.96s (baseArrivalDelay + (3-i)*arrivalInterval)
- **配置**: RocketViewActionConfig { spawnDelay=0.28, particleDelay=0.8, baseArrival=0.75, interval=0.07 }

#### 3. 普通Tile到手牌区曲线
- **核心文件**: TileView.AddToBar() → DOLerpMoveTopDown() (CatmullRom, Ease.OutExpo)
- **三段动画**: 缩放弹跳(OutQuad 1.5x→InQuad 0.75x) → 线性飞行 → 抵达弹跳(OutQuad 1.0x)
- **速度**: 15单位/s，三段式(近距线性/中距匀速/远距上限0.25s)
- **配置**: TileViewAnimationConfig { rate=15, max=0.25, min=0.1, bounceUp=0.12 }
- **手牌区内移位**: DOMove 0.15s Ease.OutSine

### 金牌曲线优化 (v3 旋转版)
- **修改文件**: GoldenCollectView.cs (完全重写 PlayCollectAnimation)
- **动画结构** (总 0.80s):
  - 阶段1 (0.12s): 点击放大 1.0→1.25x, Ease.OutBack
  - 阶段2a (0.12s): 顺时针旋转360° InQuad + 缩放 1.25→目标, 旋转逐渐加速
  - 阶段2b (0.52s): 抛物线飞行 InQuart, 旋转收尾时飞行开始, 偷跑极短
  - 阶段2c (0.06s): 砸击过冲 1.12x OutQuad+InBack
  - 阶段3: 收集粒子特效
- **缓动迭代**: InQuad→InCubic→InQuart (越来越极端的偷跑→冲刺变速)
- **ParticleCase.cs**: DoMove(Transform) 增加了 easeType/overshoot 参数(向后兼容)
