## 关卡 QA 工具开发记录（已回退，存档）

> 后续程序在编辑器中内置了此功能，WorkBuddy 侧代码已回退。以下保留作为设计参考。

### 流程分析
- Task A（质量校验）：编辑器导出CSV → Excel筛选false → 排序看花色数/方块数 → 每周重复~40分钟
- Task B（差异同步）：线上关卡组复制覆盖 → Fork看git diff → 人工确认

### 开发的功能
- `LevelFileMigrationWindow` 操作类型下拉新增 Validate / Diff 两种模式
- Validate：扫描 + ValidateExternal + 花色数[5,22] + 组数[12,120]检测
- Diff：MD5对比（Comment剥离）+ 新增/删除/修改分组展示
- 下拉列表固定加入"本地关卡文件"和"自定义路径..."特殊选项

### 关键技术点
- 组数计算照搬 StatisticView.SetTileCount（Blocker排除 + Sequences双if分支）
- RootGroupId 是 1-based 索引
- SetDeserializedFromJson() 确保 TileType 行为一致
