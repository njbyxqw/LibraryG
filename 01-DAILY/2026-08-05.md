### Mac 正常 / Windows 花色为空 — 平台差异排查

- 确认代码和数据文件在两平台完全一致，排除代码逻辑和数据差异
- 发现 `core.autocrlf=true`，存在 git 将 .bytes 当文本文件 CRLF 转换的风险
  - 已验证当前 .bytes 无 CRLF 损坏（554 LF, 0 CRLF），但根因仍可能是 git checkout 时二进制损坏
  - 建议 .gitattributes 增加 `*.bytes binary` 规则
- asmdef 引用差异：TileScape 比 meatloaf 多了 3 个 GUID，少了 6 个 GUID
- 建议：reimport .bytes、检查 Console 报错、确认 Unity Editor 版本是否一致
