# INBOX 整理 Skill

## 触发条件

用户说以下任意一句时触发：
- "归档" —— 最简触发
- "整理 INBOX" / "organize inbox"
- "清理工作区" / "清理对话" / "整理对话"

## 仓库结构约定

```
D:\LibraryG\
  ├── 00-INBOX/<日期-主题>/     ← 对话中间产物
  ├── 01-DAILY/YYYY-MM-DD.md    ← 每日日志
  ├── 02-PROJECTS/<项目名>/     ← 项目产出
  ├── 03-KNOWLEDGE/<主题>/      ← 知识库
  ├── 04-TEMPLATES/             ← 模板
  └── 05-ARCHIVE/               ← 归档
```

## 分类规则（优先级从高到低）

| 产物类型 | 判断依据 | 目标路径 |
|---------|---------|---------|
| 规范/流程/方法论 | 文件名含"规范/流程/标准/工作流" | `03-KNOWLEDGE/工作流/` |
| 技术知识（可复用） | 内容涉及技术原理，非项目特定 | `03-KNOWLEDGE/<主题>/` |
| 项目文档/报告 | 内容明确与 TileMatch/WorkBuddy 等项目相关 | `02-PROJECTS/<项目名>/` |
| 日志/工作记录 | 内容为阶段性工作汇总 | `01-DAILY/` |
| 无结论临时产物 | 草稿、临时比对、中间分析，DAILY 已有记录 | 🗑 删除 |

## 执行流程

### Phase 1: 扫描

```bash
# 列出 INBOX 下所有对话文件夹及文件（排除 attachments/）
find D:/LibraryG/00-INBOX -mindepth 1 -maxdepth 1 -not -name "attachments" -type d
# 对每个文件夹，列出其内容
ls -R D:/LibraryG/00-INBOX/<folder>/
```

### Phase 2: 分析

对每个文件：
1. **判断去向**：读取文件标题 + 前 30 行，套用分类规则
2. **同类检测**：检查目标目录是否已有同名/同类文件
3. **冲突标记**：同类文件内容有矛盾 → 标 ⚠

### Phase 3: 预览

输出格式：

```
📋 INBOX 整理建议

📁 2026-06-30-关卡数据分析工具/
├── 工作报告_关卡数据分析工具.md → 🗑 删除（临时工作产物，DAILY 已有记录）
└── 结论：文件夹清空后可删除

📁 2026-07-01-知识库分类标准/
└── （空文件夹）→ 🗑 删除

📊 汇总
├── 移动到 03-KNOWLEDGE/：0 篇
├── 移动到 02-PROJECTS/：0 篇
├── 🗑 删除：3 项
└── ⚠ 需确认：0 项

是否执行？[确认 / 逐项 / 跳过]
```

**同类检测示例**：

```
⚠ 同类文件检测
03-KNOWLEDGE/Game-Logic/ 目标下将新增：
  ├── 花色切换策略对比.md (来自 2026-07-01)
  └── 隐藏花色触发条件.md (来自 2026-07-03)
  → 两篇主题相似（关卡花色），是否合并或建索引页？
     A) 合并 B) 保持独立 C) 保持独立 + 建 MOC 索引
```

### Phase 4: 执行

用户确认后：
1. 移动文件到目标目录
2. 删除空文件夹
3. 更新 `01-DAILY/YYYY-MM-DD.md`：记录整理了什么
